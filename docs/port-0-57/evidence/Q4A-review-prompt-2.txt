## 2. Contrato proposto

Estado do plugin (por processo): `listener` (`CHyprSignalListener`, **por sessão**: existe só enquanto o plugin possui ou está iniciando um drag), `ownedAt` (geração na aquisição), `ownedTarget` (`WP<ITarget>`), `generation` (contador de `ended` vistos), `inOwnEnd`, `unloading`.

- **C1 — Aquisição só por início efetivo.** `begin`: recusa se `unloading` ou `inOwnEnd`; recusa (sem tocar) se `target()` existe. **Arma o ouvinte antes** de `beginDragTarget` (vê o `ended` de uma recusa interna, F4). Possui só se, depois da chamada: nenhuma `ended` ocorreu (`generation == G0`), `target()` não é nulo e é o alvo pedido. Senão desarma e devolve `REFUSED`.
- **C2 — Invalidação.** O ouvinte, em **qualquer** `ended`: `++generation`, zera posse e solta **a si mesmo** (seguro por F8). Atribuição conservadora: como `ended` não identifica a sessão, toda `ended` após a aquisição invalida.
- **C3 — Posse vigente** = ouvinte armado ∧ `ownedAt == generation` ∧ `ownedTarget` vivo ∧ `target() == ownedTarget`.
- **C4 — Fim (K3/K9).** Só se C3; marca `inOwnEnd` durante `endDragTarget()`. Sem posse: **não faz nada** (o host encerra no próximo botão/tecla, F7).
- **C5 — Rearm** = C4 seguido de C1, no mesmo quadro; se C4 não encerrou (sem posse), não há rearm.
- **C6 — Falha ao armar** (`listen` lança): o modelo explora iniciar **sem** posse (preserva o início de hoje); o plugin nunca encerra esse drag. **Política ainda não aprovada:** isso não prova Q4 no unload, pois uma interação do plugin pode permanecer ativa sem posse verificável. Alternativa: recusar o início e fazer rollback das flags dos chamadores. O dono deve decidir antes de produção. Exceções dentro de `beginDragTarget`/callbacks do host não têm rollback provado por este modelo.
- **C7 — Unload passo 2:** `unloading = true`; se C3, C4; depois **sempre** solta o ouvinte (mesmo armado por um alvo morto em silêncio), antes de remover ouvintes/decorações/timers e de qualquer `dlclose`.

**Premissas (limites da API):** A1 thread única (H-THREAD); A2 = F1 (verificado); A3 nenhum componente chama `beginDragTarget` com drag ativo (host verificado em F2; **plugins de terceiros: premissa**); A4 `ended` síncrono, uma por fim com alvo vivo (F3, verificado); A5 o unload não ocorre de dentro de uma emissão de `ended` (Q3/H-Q3, F8).

**Geração — conclusão verificada:** `ended` sem argumento só permite saber "alguma sessão terminou depois da aquisição". Com ouvinte **por sessão**, a geração é **redundante** (o próprio desarme já invalida; mutantes q09–q12 sobrevivem por isso), mas é ela que dá o retorno correto de `begin` na recusa sem reset de alvo (F5; mutante q13). Com ouvinte **permanente** (P7 §5), a geração é **essencial** (q14, q15). Proposta: ouvinte por sessão + geração como defesa.

// SPDX-License-Identifier: MIT
// Part of kwinish (Copyright (c) 2026 lhen).
// Starting a pointer drag (move/resize) on Hyprland 0.57, where CKeybindManager::changeMouseBindMode is gone. This is
// the START half of the 0.56.2 body (O:managers/KeybindManager.cpp:949-968) on the 0.57 primitives, nothing more:
//   - a drag already in progress (anyone's) is left alone: nothing is ended, nothing is started;
//   - the window is the one under the pointer (as before; for the menu's resize that is the 0.56.2 behaviour too);
//   - a non-fullscreen MOVE asks the window's decorations first (INPUT_TYPE_DRAG_START), as before;
//   - beginDragTarget keeps its defaults (no forced edge, exclusiveDeviceGrab = false), as before.
// Ending a drag is NOT here: without knowing whose drag is active (session ownership, Q4), ending would also end drags
// started by other components. See docs/port-0-57/P8-DRAG.md.
#pragma once

#include <hyprland/src/desktop/state/ViewHitTester.hpp>
#include <hyprland/src/desktop/state/ViewState.hpp>
#include <hyprland/src/desktop/view/window/Window.hpp>
#include <hyprland/src/desktop/view/window/WindowPresentation.hpp>
#include <hyprland/src/layout/LayoutManager.hpp>
#include <hyprland/src/layout/supplementary/DragController.hpp>
#include <hyprland/src/layout/target/Target.hpp>
#include <hyprland/src/managers/fullscreen/FullscreenController.hpp>
#include <hyprland/src/managers/input/InputManager.hpp>

#include <cstdint>

namespace KwDrag {
    enum eBeginResult : uint8_t {
        BEGIN_STARTED = 0,      // beginDragTarget was called (the host may still refuse inside it)
        BEGIN_ALREADY_DRAGGING, // a drag was in progress: left untouched
        BEGIN_NO_WINDOW,        // nothing under the pointer (0.56.2: passEvent)
        BEGIN_REFUSED_BY_DECO,  // a decoration took the drag start (0.56.2: passEvent = false)
        BEGIN_BAD_MODE,         // not MBIND_MOVE / MBIND_RESIZE: nothing done
    };

    // MODE must be MBIND_MOVE or MBIND_RESIZE; anything else does nothing (0.56.2 ended the drag for MBIND_INVALID,
    // which this helper deliberately does not do).
    inline eBeginResult begin(eMouseBindMode MODE) {
        if (MODE != MBIND_MOVE && MODE != MBIND_RESIZE)
            return BEGIN_BAD_MODE;
        if (g_layoutManager->dragController()->target())
            return BEGIN_ALREADY_DRAGGING;

        const auto      MOUSECOORDS = g_pInputManager->getMouseCoordsInternal();
        const PHLWINDOW PWINDOW =
            Desktop::viewState()->hitTest().windowAt(MOUSECOORDS, Desktop::View::RESERVED_EXTENTS | Desktop::View::INPUT_EXTENTS | Desktop::View::ALLOW_FLOATING);

        if (!PWINDOW)
            return BEGIN_NO_WINDOW;

        if (!Fullscreen::controller()->isFullscreen(PWINDOW) && MODE == MBIND_MOVE) {
            if (PWINDOW->presentation().checkInputOnDecorations(INPUT_TYPE_DRAG_START, MOUSECOORDS))
                return BEGIN_REFUSED_BY_DECO;
        }

        g_layoutManager->beginDragTarget(PWINDOW->layoutTarget(), MODE);
        return BEGIN_STARTED;
    }
}

// - Signals are the REAL Hyprutils::Signal::CSignalT<> / CHyprSignalListener (installed hyprutils 0.14.3).

using Hyprutils::Signal::CSignalT;

enum eMode : int8_t { M_INVALID = -1, M_MOVE = 0, M_RESIZE = 1 };

struct STarget {
    std::string name;
    bool        mapped = true, hasWorkspace = true, hasWindow = true, fsWorkspaceReject = false, decoTakesDragEnd = false;
};
using SPT = CSharedPointer<STarget>;
using WPT = CWeakPointer<STarget>;

inline std::vector<std::string> g_log;
inline void                     L(const std::string& s) { g_log.push_back(s); }

struct CDragModel {
    WPT   m_target;
    eMode m_mode = M_INVALID;
    struct {
        CSignalT<> ended;
    } m_events;
    std::function<void()> onFocusDuringEnd;     // stands for fullWindowFocus -> window.active listeners
    std::function<void()> onDecoDragEnd;        // stands for checkInputOnDecorations(INPUT_TYPE_DRAG_END) callbacks
    int                   endedEmissions = 0;

    SPT target() const { return m_target.lock(); }

    void dragBegin(SPT t, eMode mode) { // U:158-251
        m_target = t;                    // :160  (no guard: callers must check target() first)
        m_mode   = mode;
        const auto D = m_target.lock();
        if (!D->mapped) { L("dragBegin: invalid window -> dragEnd"); dragEnd(); return; }        // :173-177
        if (!D->hasWorkspace) { L("dragBegin: no workspace -> dragEnd"); dragEnd(); return; }     // :179-183
        if (D->fsWorkspaceReject) { L("dragBegin: fullscreen workspace reject -> dragEnd"); dragEnd(); return; } // updateDragWindow :123-126
        L("dragBegin: started " + D->name);
    }

    bool dragEnd() { // U:252-334
        auto D = m_target.lock();
        if (!D)
            return false;                                                              // :255-256, no `ended`
        Hyprutils::Utils::CScopeGuard notifyEnded([this] { ++endedEmissions; m_events.ended.emit(); }); // :258
        if (!D->mapped) {                                                              // :262-271
            if (D->hasWindow)
                m_target.reset();
            m_mode = M_INVALID;
            return true;
        }
        m_target.reset();                                                              // :274 (before callbacks)
        if (m_mode == M_MOVE && D->decoTakesDragEnd) {                                 // :287-293
            if (auto f = onDecoDragEnd) f(); // copy: a callback may clear itself
            m_mode = M_INVALID;
            return true;
        }
        if (auto f = onDecoDragEnd) f();
        if (auto f = onFocusDuringEnd) f();                                      // :324 fullWindowFocus
        m_mode = M_INVALID;
        return true;
    }
};

// ---- the plugin side ---------------------------------------------------------------------------------------------
// Start helper = plugin/hostDrag.hpp KwDrag::begin semantics (guard: refuse if any drag is active).
enum eBeginResult { STARTED, ALREADY, REFUSED };

// Candidate end policies WITHOUT ownership (what K3 could do today) -------------------------------------------------
struct CNaive {
    SPT  remembered;
    int  kind = 0; // 0 unconditional, 1 target equality, 2 target+mode
    eMode rememberedMode = M_INVALID;
    eBeginResult begin(SPT t, eMode m) {
        if (g_dc->target()) return ALREADY;
        g_dc->dragBegin(t, m);
        remembered = t; rememberedMode = m;
        return g_dc->target() ? STARTED : REFUSED;
    }
    bool endIfOurs() {
        const auto T = g_dc->target();
        if (!T) return false;
        if (kind == 1 && T != remembered) return false;
        if (kind == 2 && (T != remembered || g_dc->m_mode != rememberedMode)) return false;
        return g_dc->dragEnd();
    }
    bool owns() const { return true; }
};

// PROPOSED contract (Q4-A) -------------------------------------------------------------------------------------------
// Ownership = (a listener on `ended` armed only for our session) AND (no `ended` since acquisition) AND (our target
// still alive) AND (it is the controller's current target). Acquired only when our begin really started a session.
struct COwnership {
    uint64_t            generation = 0;     // bumped by every `ended` seen while armed
    std::optional<uint64_t> ownedAt;        // generation at acquisition; nullopt = not owning
    WPT                 ownedTarget;
    CHyprSignalListener listener;           // session-scoped: exists only while owning (or while starting)
    bool                inOwnEnd = false;   // we are inside our own endDragTarget()
    bool                unloading = false;
    bool                failListen = false; // test hook: listen() throws (allocation failure)
    int                 handlerRuns = 0;

    void disarm() { ownedAt.reset(); ownedTarget.reset(); listener.reset(); }

    bool owns() const { return ownedAt && *ownedAt == generation && !ownedTarget.expired() && g_dc->target() == ownedTarget.lock() && listener; }

    eBeginResult begin(SPT t, eMode m) {
        if (unloading || inOwnEnd)                // no start during unload or inside our own end (reentrancy)
            return REFUSED;
        if (g_dc->target())
            return ALREADY;                       // anyone's drag: untouched (P8-B guard)
        try {                                     // arm BEFORE begin, so a refusal-`ended` inside dragBegin is seen
            if (failListen) throw std::bad_alloc();
            listener = g_dc->m_events.ended.listen([this] { ++handlerRuns; ++generation; disarm(); }); // may reset itself: safe (snapshot SP)
        } catch (const std::bad_alloc&) {
            // rollback policy: start WITHOUT ownership (preserves today's start behaviour; the plugin will not end it,
            // the host ends it on the next button/key)
            g_dc->dragBegin(t, m);
            return g_dc->target() ? STARTED : REFUSED;
        }
        const uint64_t G0 = generation;
        g_dc->dragBegin(t, m);
        if (generation != G0 || !g_dc->target() || g_dc->target() != t) { // refused inside dragBegin (ended fired) or replaced
            disarm();
            return REFUSED;
        }
        ownedAt     = G0;
        ownedTarget = t;
        return STARTED;
    }

    bool endIfOurs() { // K3/K9 replacement
        if (!owns())
            return false;
        inOwnEnd       = true;
        const bool R   = g_dc->dragEnd(); // emits `ended` -> our handler disarms
        inOwnEnd       = false;
        if (ownedAt) disarm();            // e.g. host emitted nothing (cannot happen with a live target; defensive)
        return R;
    }

    void unloadStep2() { // PLUGIN_EXIT step 2 (Q4), before removing listeners/decorations
        unloading = true;
        if (owns())
            (void)endIfOurs();
        disarm();        // listener destroyed before the module is unmapped
    }
};

// Variant with a plugin-lifetime listener (P7 §5 item 6): the generation counter is what invalidates ownership.
struct CPersistent {
    uint64_t                generation = 0;
    std::optional<uint64_t> ownedAt;
    WPT                     ownedTarget;
    CHyprSignalListener     listener;
    void                    init() { listener = g_dc->m_events.ended.listen([this] { ++generation; }); }
    bool owns() const { return ownedAt && *ownedAt == generation && !ownedTarget.expired() && g_dc->target() == ownedTarget.lock(); }
    eBeginResult begin(SPT t, eMode m) {
        if (g_dc->target()) return ALREADY;
        const auto G0 = generation;
        g_dc->dragBegin(t, m);
        if (generation != G0 || g_dc->target() != t) return REFUSED;
        ownedAt = G0; ownedTarget = t;
        return STARTED;
    }
    bool endIfOurs() { if (!owns()) return false; ownedAt.reset(); return g_dc->dragEnd(); }
};

static SPT mk(const char* n) { auto t = makeShared<STarget>(); t->name = n; return t; }

// Run one scenario for a policy P. Returns {thirdPartyDragEndedByPlugin, ownDragNotEnded}
template <typename P>
static void scenarios(const char* NAME, bool expectSafe) {
    auto run = [&](const char* sc, auto body) {
        CDragModel dc; g_dc = &dc; g_log.clear();
        P p;
        if constexpr (requires { p.init(); }) p.init();
        if constexpr (requires { p.kind; }) p.kind = std::strstr(NAME, "unconditional") ? 0 : std::strstr(NAME, "target+mode") ? 2 : 1;
        body(dc, p, sc);
    };
    // S1 liveness: our drag, we end it
    run("S1", [&](CDragModel& dc, P& p, const char* sc) {
        auto A = mk("A");
        const auto R = p.begin(A, M_MOVE);
        const bool ended = p.endIfOurs();
        check(R == STARTED && ended && !dc.target(), std::string(NAME) + " " + sc + ": own drag started and ended by the plugin (liveness)");
    });
    // S2 the counterexample: host ends ours (key), user starts on the SAME window, plugin release
    run("S2", [&](CDragModel& dc, P& p, const char* sc) {
        auto A = mk("A");
        p.begin(A, M_MOVE);
        dc.dragEnd();                      // host: key press (U:keybinds/Manager.cpp:223)
        dc.dragBegin(A, M_MOVE);           // user's bind drag on the same window/target, same mode
        const bool ended = p.endIfOurs();
        check(expectSafe ? (!ended && dc.target() == A) : (ended && !dc.target()),
              std::string(NAME) + " " + sc + (expectSafe ? ": user drag on the SAME window kept" : ": user drag on the same window ENDED (counterexample reproduced)"));
    });
    if (!expectSafe) return;
    // S3 begin refused because a third-party drag is active; plugin end must not touch it
    run("S3", [&](CDragModel& dc, P& p, const char* sc) {
        auto A = mk("A"), X = mk("X");
        dc.dragBegin(X, M_MOVE);
        const auto R = p.begin(A, M_MOVE);
        check(R == ALREADY && !p.endIfOurs() && dc.target() == X, std::string(NAME) + " " + sc + ": third-party drag active -> no ownership, untouched");
    });
    // S4 refusal inside dragBegin (unmapped / no workspace / fullscreen workspace) -> `ended` inside begin -> no ownership
    for (int v = 0; v < 4; ++v)
        run("S4", [&](CDragModel& dc, P& p, const char* sc) {
            auto A = mk("A");
            if (v == 3) { A->mapped = false; A->hasWindow = false; } // refusal that emits `ended` WITHOUT resetting the target (U:262-271)
            else (v == 0 ? A->mapped : v == 1 ? A->hasWorkspace : A->fsWorkspaceReject) = (v == 2);
            const auto R = p.begin(A, M_MOVE);
            auto X = mk("X");
            dc.dragBegin(X, M_MOVE); // later third-party drag
            check(R == REFUSED && !p.endIfOurs() && dc.target() == X, std::string(NAME) + " " + sc + "." + std::to_string(v) + ": refused inside dragBegin -> no ownership; later third-party drag kept");
        });
    // S5 our target dies WITHOUT `ended` (dragEnd returns early on an expired target), then a third-party drag
    run("S5", [&](CDragModel& dc, P& p, const char* sc) {
        SPT A = mk("A");
        p.begin(A, M_MOVE);
        A = nullptr;                       // target destroyed; controller's WP expires silently
        dc.dragEnd();                      // host: nothing to end -> no `ended`
        auto X = mk("X");
        dc.dragBegin(X, M_MOVE);
        check(!p.endIfOurs() && dc.target() == X, std::string(NAME) + " " + sc + ": our target died silently (no ended) -> third-party drag kept");
    });
    // S7 reentrancy: inside the host's dragEnd of OUR session a callback starts a third-party drag before `ended`
    run("S7", [&](CDragModel& dc, P& p, const char* sc) {
        auto A = mk("A"), X = mk("X");
        p.begin(A, M_MOVE);
        dc.onFocusDuringEnd = [&] { dc.onFocusDuringEnd = nullptr; dc.dragBegin(X, M_MOVE); }; // window.active listener of someone else
        dc.dragEnd();                      // host ends ours; X starts reentrantly; then `ended` (for A) is emitted
        check(!p.endIfOurs() && dc.target() == X, std::string(NAME) + " " + sc + ": reentrant third-party start during host dragEnd -> kept");
    });
    // S8 reentrancy during OUR OWN end: a callback tries to start a plugin drag
    run("S8", [&](CDragModel& dc, P& p, const char* sc) {
        auto A = mk("A"), B = mk("B");
        p.begin(A, M_MOVE);
        eBeginResult inner = ALREADY;
        dc.onFocusDuringEnd = [&] { dc.onFocusDuringEnd = nullptr; inner = p.begin(B, M_MOVE); };
        p.endIfOurs();
        const bool ownsAfter = p.owns();
        if constexpr (requires { p.inOwnEnd; })
            check(inner == REFUSED && !dc.target() && !ownsAfter, std::string(NAME) + " " + sc + ": plugin start refused while inside its own end (no orphan session)");
        else
            check(!ownsAfter, std::string(NAME) + " " + sc + ": reentrant own start: ownership not kept (conservative; started=" + std::to_string(inner == STARTED) + ")");
    });
    // S9 DRAG_END decoration early return path still emits `ended`
    run("S9", [&](CDragModel& dc, P& p, const char* sc) {
        auto A = mk("A");
        A->decoTakesDragEnd = true;
        p.begin(A, M_MOVE);
        dc.dragEnd();
        dc.dragBegin(A, M_MOVE);
        check(!p.endIfOurs() && dc.target() == A, std::string(NAME) + " " + sc + ": decoration-early-return end still invalidates; later user drag kept");
    });
    // S10 target without window: dragEnd emits `ended` but does NOT reset m_target (U:262-271)
    run("S10", [&](CDragModel& dc, P& p, const char* sc) {
        auto A = mk("A");
        p.begin(A, M_MOVE);
        A->mapped = false; A->hasWindow = false;
        dc.dragEnd();                     // ended emitted, target still set
        check(!p.endIfOurs() && dc.target() == A, std::string(NAME) + " " + sc + ": `ended` without target reset -> ownership dropped (conservative)");
    });
}

    std::printf("== naive policies (no ownership): the counterexample\n");
    scenarios<CNaive>("unconditional", false);
    scenarios<CNaive>("target equality", false);
    scenarios<CNaive>("target+mode", false);
    std::printf("== proposed: session-scoped listener + generation + target WP\n");
    scenarios<COwnership>("proposed", true);
    std::printf("== variant: plugin-lifetime listener + generation\n");
    scenarios<CPersistent>("persistent", true);

    // ---- premise A3: an UNGUARDED third-party beginDragTarget while ours is active, on the SAME target -------------
    {
        CDragModel dc; g_dc = &dc; COwnership p; auto A = mk("A");

        dc.dragBegin(A, M_RESIZE);         // replaces m_target without `ended` (U:160 has no guard)
        const bool ended = p.endIfOurs();
        check(ended, "premise A3 needed: unguarded re-begin on the same target is indistinguishable (proposed ENDS it) -> documented as limit");
    }
    // ---- listener lifetime with the real hyprutils signal --------------------------------------------------------
    {
        CDragModel dc; g_dc = &dc; COwnership p; auto A = mk("A");
        p.begin(A, M_MOVE);
        p.endIfOurs();                     // handler resets its own listener during the emission
        check(p.handlerRuns == 1 && !p.listener, "listener reset inside its own handler: ran once, no crash (ASan), disarmed");
        const int before = p.handlerRuns;
        auto B = mk("B");
        dc.dragBegin(B, M_MOVE); dc.dragEnd(); // later sessions emit `ended`
        check(p.handlerRuns == before, "after disarm, later `ended` emissions do not call the plugin");
    }
    {
        // a listener registered during an emission is not called by that emission (snapshot)
        CDragModel dc; g_dc = &dc; int late = 0; CHyprSignalListener l2;
        auto l1 = dc.m_events.ended.listen([&] { l2 = dc.m_events.ended.listen([&] { ++late; }); });
        auto A = mk("A"); dc.dragBegin(A, M_MOVE); dc.dragEnd();
        check(late == 0, "hyprutils: listener added during emission is not invoked by it");
    }
    {
        // a listener dropped by its owner BEFORE its turn in the same emission is skipped (strongRef()==1)
        CDragModel dc; g_dc = &dc; int second = 0; CHyprSignalListener l2;
        auto l1 = dc.m_events.ended.listen([&] { l2.reset(); });
        l2 = dc.m_events.ended.listen([&] { ++second; });
        auto A = mk("A"); dc.dragBegin(A, M_MOVE); dc.dragEnd();
        check(second == 0, "hyprutils: listener released earlier in the same emission is skipped");
    }
    {
        // Q3 limit: if the module drops its listener from INSIDE an `ended` emission (e.g. unload triggered by another
        // listener), the emission's snapshot still holds the CSignalListener: its std::function is destroyed AFTER our
        // reset, i.e. after an unmap if unload were synchronous there. Measured with a destructor counter.
        struct SProbe { int* d = nullptr; ~SProbe() { if (d) ++*d; } }; // no temporary: only the shared instance counts
        CDragModel dc; g_dc = &dc; int destroyed = 0, destroyedAtReset = -1, oursRan = 0;
        CHyprSignalListener ours;
        // `other` is registered first, so it runs first in the emission and drops our listener ("unload" inside it)
        auto other = dc.m_events.ended.listen([&] { ours.reset(); destroyedAtReset = destroyed; });
        {
            auto probe = std::make_shared<SProbe>();
            probe->d   = &destroyed;
            ours       = dc.m_events.ended.listen([probe, &oursRan] { (void)probe; ++oursRan; });
        }
        auto A = mk("A"); dc.dragBegin(A, M_MOVE); dc.dragEnd();
        check(oursRan == 0 && destroyedAtReset == 0 && destroyed == 1,
              "Q3 limit reproduced: a plugin listener dropped inside an `ended` emission is skipped, but its handler state is destroyed only at the end of the emission (after the drop)");
    }
    // ---- unload step 2 ---------------------------------------------------------------------------------------------
    {

        p.unloadStep2();
        check(!dc.target() && !p.listener && dc.endedEmissions == 1, "unload step 2 with own drag: ended once, listener destroyed");
    }

        p.begin(A, M_MOVE); dc.dragEnd(); dc.dragBegin(X, M_MOVE);
        p.unloadStep2();
        check(dc.target() == X && !p.listener, "unload step 2 with a third-party drag (after ours ended): untouched, listener destroyed");
        check(p.begin(A, M_MOVE) == REFUSED, "no start after unload step 2 began");
    }
    {
        // our target dies silently while we own it; unload must still destroy the armed listener
        CDragModel dc; g_dc = &dc; COwnership p; SPT A = mk("A");
        p.begin(A, M_MOVE);
        A = nullptr;
        p.unloadStep2();
        check(!p.listener && dc.endedEmissions == 0, "unload step 2 after a silent target death: no end attempted, listener destroyed anyway");
    }
    // Stale emission snapshot: the first listener starts a NEW plugin session while the old `ended` is being emitted.
    // Replacing the per-session listener drops its old owner ref; real hyprutils skips the old snapshot callback.
    {
        CDragModel dc; g_dc = &dc; COwnership p; auto A=mk("A"), B=mk("B");
        eBeginResult inner=REFUSED;
        auto first=dc.m_events.ended.listen([&] { inner=p.begin(B,M_MOVE); });
        p.begin(A,M_MOVE);
        dc.dragEnd();
        check(inner==STARTED && p.owns() && dc.target()==B && p.handlerRuns==0,
              "stale ended snapshot: old listener skipped after replacement; new session owns B, no old callback clears it");
        first.reset();
        p.endIfOurs();
        check(!p.owns() && !dc.target(), "new session from ended listener is ended normally on next release");
    }
    {
        CDragModel dc; g_dc=&dc; COwnership p; auto A=mk("A");
        p.begin(A,M_MOVE);
        const bool ended=p.endIfOurs();
        const auto r=ended?p.begin(A,M_RESIZE):REFUSED;
        check(ended && r==STARTED && p.owns() && dc.m_mode==M_RESIZE, "rearm: own end then begin acquires a fresh session");
        p.endIfOurs();
    }
    {
        CDragModel dc; g_dc=&dc; COwnership p; auto A=mk("A"), X=mk("X");
        p.begin(A,M_MOVE);
        dc.onFocusDuringEnd=[&] { dc.onFocusDuringEnd=nullptr; dc.dragBegin(X,M_MOVE); };
        const bool ended=p.endIfOurs();
        const auto r=ended?p.begin(A,M_RESIZE):REFUSED;
        check(ended && r==ALREADY && !p.owns() && dc.target()==X,
              "rearm: third-party start during end is kept; following begin does not adopt it");
    }
    // ---- initialization failure ------------------------------------------------------------------------------------
    {
        CDragModel dc; g_dc = &dc; COwnership p; auto A = mk("A");
        p.failListen = true;
        const auto R = p.begin(A, M_MOVE);
        check(R == STARTED && !p.owns() && !p.endIfOurs() && dc.target() == A, "listen() fails: drag started WITHOUT ownership (start behaviour kept); plugin never ends it");
    }
    std::printf("%d ok, %d failed\n", oks, fails);
    return fails ? 1 : 0;
}

static bool isResizeMode(eMouseBindMode mode) {
    return mode == MBIND_RESIZE || mode == MBIND_RESIZE_FORCE_RATIO || mode == MBIND_RESIZE_BLOCK_RATIO;

static std::string_view cursorForResizeEdge(eRectCorner edge) {
    if (edgeTop(edge) && edgeLeft(edge))
        return "nw-resize";
    if (edgeTop(edge) && edgeRight(edge))
        return "ne-resize";
    if (edgeBottom(edge) && edgeRight(edge))
        return "se-resize";
    if (edgeBottom(edge) && edgeLeft(edge))
        return "sw-resize";
    if (edgeTop(edge))
        return "n-resize";
    if (edgeBottom(edge))
        return "s-resize";
    if (edgeLeft(edge))
        return "w-resize";
    if (edgeRight(edge))
        return "e-resize";

    return "se-resize";
}

bool CDragStateController::updateDragWindow() {
    const auto  DRAGGINGTARGET = m_target.lock();
    const bool  WAS_FULLSCREEN = DRAGGINGTARGET->window() ? Fullscreen::controller()->isFullscreen(DRAGGINGTARGET->window()) : false;
    static auto PDRAGCENTER    = CConfigValue<Config::BOOL>("binds:drag_center_window");

    // geometry before we un-fullscreen / untile, needed to map the grab point onto the new window
    const CBox PRE_DRAG_BOX = DRAGGINGTARGET->position();

    // places the window under the cursor after its geometry changed. Without drag_center_window, the
    // grab point keeps its relative position: grabbing 80% across the fullscreen surface leaves the
    // cursor 80% across the restored window
    const auto MAPDRAGHOTSPOT = [this](const SP<ITarget>& target, const CBox& oldBox) {
        const auto MOUSECOORDS = g_pInputManager->getMouseCoordsInternal();
        const auto NEWSIZE     = target->position().size();
        const auto OLDSIZE     = oldBox.size();

        if (*PDRAGCENTER)
            m_dragHotspot = NEWSIZE / 2.F;
        else {
            const Vector2D REL = {OLDSIZE.x > 0 ? (MOUSECOORDS.x - oldBox.pos().x) / OLDSIZE.x : 0.5, OLDSIZE.y > 0 ? (MOUSECOORDS.y - oldBox.pos().y) / OLDSIZE.y : 0.5};

            m_dragHotspot = REL.clamp(Vector2D{0.F, 0.F}, Vector2D{1.F, 1.F}) * NEWSIZE;
        }

        target->setPositionGlobal(CBox{MOUSECOORDS - m_dragHotspot, NEWSIZE});
    };

    if (m_dragThresholdReached) {
        if (WAS_FULLSCREEN) {
            LOG(Log::DEBUG, "Dragging a fullscreen window");
            Fullscreen::controller()->setFullscreenMode(DRAGGINGTARGET->window(), Fullscreen::FSMODE_NONE);
        }

        const auto PWORKSPACE     = DRAGGINGTARGET->workspace();
        const auto DRAGGINGWINDOW = DRAGGINGTARGET->window();

        if (Fullscreen::controller()->hasFullscreen(PWORKSPACE) && (!DRAGGINGTARGET->floating() || !DRAGGINGWINDOW->isAllowedOverFullscreen())) {
            LOG(Log::DEBUG, "Rejecting drag on a fullscreen workspace. (window under fullscreen)");
            dragEnd();
            return true;
        }
    }

    m_draggingTiled                   = false;
    m_draggingWindowOriginalFloatSize = DRAGGINGTARGET->lastFloatingSize();

    if (WAS_FULLSCREEN && DRAGGINGTARGET->floating() && m_dragThresholdReached) {
        MAPDRAGHOTSPOT(DRAGGINGTARGET, PRE_DRAG_BOX);
    } else if (!DRAGGINGTARGET->floating() && m_dragMode == MBIND_MOVE) {
        Vector2D MINSIZE = DRAGGINGTARGET->minSize().value_or(Vector2D{MIN_WINDOW_SIZE, MIN_WINDOW_SIZE});
        DRAGGINGTARGET->rememberFloatingSize((DRAGGINGTARGET->position().size() * 0.8489).clamp(MINSIZE, Vector2D{}).floor());

        if (m_dragThresholdReached) {
            g_layoutManager->changeFloatingMode(DRAGGINGTARGET);
            m_draggingTiled = true;

            MAPDRAGHOTSPOT(DRAGGINGTARGET, PRE_DRAG_BOX);
        }
    }

    const auto DRAG_ORIGINAL_BOX = DRAGGINGTARGET->position();

    m_beginDragXY              = g_pInputManager->getMouseCoordsInternal();
    m_beginDragUntransformedXY = Pointer::mgr()->untransformedPosition();
    m_beginDragPositionXY      = DRAG_ORIGINAL_BOX.pos();
    m_beginDragSizeXY          = DRAG_ORIGINAL_BOX.size();
    m_lastDragXY               = m_beginDragXY;
    m_dragHotspot              = m_beginDragXY - m_beginDragPositionXY;

    return false;
}

void CDragStateController::dragBegin(SP<ITarget> target, eMouseBindMode mode, std::optional<eRectCorner> forcedEdge, bool exclusiveDeviceGrab) {
    m_target              = target;
    m_dragMode            = mode;
    m_draggingTiled       = false;
    m_forcedGrabbedCorner = forcedEdge;
    m_exclusiveDeviceGrab = exclusiveDeviceGrab;
    m_grabbedCorner       = CORNER_NONE;

    const auto  DRAGGINGTARGET = m_target.lock();
    static auto PDRAGTHRESHOLD = CConfigValue<Config::INTEGER>("binds:drag_threshold");

    m_mouseMoveEventCount = 1;
    m_beginDragSizeXY     = Vector2D();

    // Window will be floating. Let's check if it's valid. It should be, but I don't like crashing.
    if (!validMapped(DRAGGINGTARGET->window())) {
        LOG(Log::ERR, "Dragging attempted on an invalid window (not mapped)");
        dragEnd();
        return;
    }

    if (!DRAGGINGTARGET->workspace()) {
        LOG(Log::ERR, "Dragging attempted on an invalid window (no workspace)");
        dragEnd();
        return;
    }

    // Try to pick up dragged window now if drag_threshold is disabled
    // or at least update dragging related variables for the cursors
    m_dragThresholdReached = *PDRAGTHRESHOLD <= 0;
    if (updateDragWindow())
        return;

    // get the grab corner
    static auto RESIZECORNER = CConfigValue<Config::INTEGER>("general:resize_corner");
    if (m_forcedGrabbedCorner && *m_forcedGrabbedCorner != CORNER_NONE) {
        m_grabbedCorner = *m_forcedGrabbedCorner;
        Pointer::Cursor::overrideController->setOverride(std::string{cursorForResizeEdge(m_grabbedCorner)}, Pointer::Cursor::CURSOR_OVERRIDE_SPECIAL_ACTION);
    } else if (*RESIZECORNER != 0 && *RESIZECORNER <= 4 && DRAGGINGTARGET->floating()) {
        switch (*RESIZECORNER) {
            case 1:
                m_grabbedCorner = CORNER_TOPLEFT;
                Pointer::Cursor::overrideController->setOverride("nw-resize", Pointer::Cursor::CURSOR_OVERRIDE_SPECIAL_ACTION);
                break;
            case 2:
                m_grabbedCorner = CORNER_TOPRIGHT;
                Pointer::Cursor::overrideController->setOverride("ne-resize", Pointer::Cursor::CURSOR_OVERRIDE_SPECIAL_ACTION);
                break;
            case 3:
                m_grabbedCorner = CORNER_BOTTOMRIGHT;
                Pointer::Cursor::overrideController->setOverride("se-resize", Pointer::Cursor::CURSOR_OVERRIDE_SPECIAL_ACTION);
                break;
            case 4:
                m_grabbedCorner = CORNER_BOTTOMLEFT;
                Pointer::Cursor::overrideController->setOverride("sw-resize", Pointer::Cursor::CURSOR_OVERRIDE_SPECIAL_ACTION);
                break;
        }
    } else if (m_beginDragXY.x < m_beginDragPositionXY.x + m_beginDragSizeXY.x / 2.F) {
        if (m_beginDragXY.y < m_beginDragPositionXY.y + m_beginDragSizeXY.y / 2.F) {
            m_grabbedCorner = CORNER_TOPLEFT;
            Pointer::Cursor::overrideController->setOverride("nw-resize", Pointer::Cursor::CURSOR_OVERRIDE_SPECIAL_ACTION);
        } else {
            m_grabbedCorner = CORNER_BOTTOMLEFT;
            Pointer::Cursor::overrideController->setOverride("sw-resize", Pointer::Cursor::CURSOR_OVERRIDE_SPECIAL_ACTION);
        }
    } else {
        if (m_beginDragXY.y < m_beginDragPositionXY.y + m_beginDragSizeXY.y / 2.F) {
            m_grabbedCorner = CORNER_TOPRIGHT;
            Pointer::Cursor::overrideController->setOverride("ne-resize", Pointer::Cursor::CURSOR_OVERRIDE_SPECIAL_ACTION);
        } else {
            m_grabbedCorner = CORNER_BOTTOMRIGHT;
            Pointer::Cursor::overrideController->setOverride("se-resize", Pointer::Cursor::CURSOR_OVERRIDE_SPECIAL_ACTION);
        }
    }

    if (!isResizeMode(m_dragMode))
        Pointer::Cursor::overrideController->setOverride("grabbing", Pointer::Cursor::CURSOR_OVERRIDE_SPECIAL_ACTION);

    if (m_exclusiveDeviceGrab)
        g_pSeatManager->setPointerFocus(nullptr, {});

    DRAGGINGTARGET->damageEntire();

    Keybinds::mgr()->shadowBinds();

    if (DRAGGINGTARGET->window()) {
        Desktop::focusState()->rawWindowFocus(DRAGGINGTARGET->window(), Desktop::FOCUS_REASON_DESKTOP_STATE_CHANGE);
        Desktop::windowState()->raise(DRAGGINGTARGET->window());
    }

    if (isResizeMode(m_dragMode))
        setClientResizingState(DRAGGINGTARGET, true);
}
bool CDragStateController::dragEnd() {
    auto draggingTarget = m_target.lock();

    if (!draggingTarget)
        return false;

    Hyprutils::Utils::CScopeGuard notifyEnded([this] { m_events.ended.emit(); });

    m_mouseMoveEventCount = 1;

    if (!validMapped(draggingTarget->window())) {
        if (draggingTarget->window()) {
            Pointer::Cursor::overrideController->unsetOverride(Pointer::Cursor::CURSOR_OVERRIDE_SPECIAL_ACTION);
            m_target.reset();
        }
        m_dragMode            = MBIND_INVALID;
        m_exclusiveDeviceGrab = false;
        m_forcedGrabbedCorner.reset();
        return true;
    }

    Pointer::Cursor::overrideController->unsetOverride(Pointer::Cursor::CURSOR_OVERRIDE_SPECIAL_ACTION);
    m_target.reset();
    m_wasDraggingWindow = true;

    if (m_dragMode == MBIND_MOVE && draggingTarget->window()) {
        draggingTarget->damageEntire();

        const auto DRAGGING_WINDOW = draggingTarget->window();

        const auto MOUSECOORDS = g_pInputManager->getMouseCoordsInternal();
        PHLWINDOW  pWindow =
            Desktop::viewState()->hitTest().windowAt(MOUSECOORDS, Desktop::View::RESERVED_EXTENTS | Desktop::View::INPUT_EXTENTS | Desktop::View::ALLOW_FLOATING, DRAGGING_WINDOW);

        if (pWindow) {
            if (pWindow->presentation().checkInputOnDecorations(INPUT_TYPE_DRAG_END, MOUSECOORDS, DRAGGING_WINDOW)) {
                m_wasDraggingWindow   = false;
                m_dragMode            = MBIND_INVALID;
                m_exclusiveDeviceGrab = false;
                m_forcedGrabbedCorner.reset();
                return true;
            }

            const bool  FLOATEDINTOTILED = !pWindow->isFloating() && !m_draggingTiled;
            static auto PDRAGINTOGROUP   = CConfigValue<Config::INTEGER>("group:drag_into_group");

            if (pWindow->grouping().group() && DRAGGING_WINDOW->grouping().canBeGroupedInto(pWindow->grouping().group()) && *PDRAGINTOGROUP == 1 && !FLOATEDINTOTILED) {
                pWindow->grouping().group()->add(DRAGGING_WINDOW);
                // fix the draggingTarget, now it's DRAGGING_WINDOW
                draggingTarget = DRAGGING_WINDOW->windowTarget();
            }
        }
    }

    if (const auto W = draggingTarget->window(); W) {
        W->effects().resetMotionBlur();
        W->presentation().clearFloatingOffset();
    }

    if (m_draggingTiled) {
        // make sure to check if we are floating because drag into group could make us tiled already
        if (draggingTarget->floating())
            g_layoutManager->changeFloatingMode(draggingTarget);

        draggingTarget->rememberFloatingSize(m_draggingWindowOriginalFloatSize);
    }

    draggingTarget->damageEntire();

    g_layoutManager->setTargetGeom(draggingTarget->position(), draggingTarget);

    Desktop::focusState()->fullWindowFocus(draggingTarget->window(), Desktop::FOCUS_REASON_DESKTOP_STATE_CHANGE);

    m_wasDraggingWindow = false;
    if (isResizeMode(m_dragMode))
        setClientResizingState(draggingTarget, false);

    m_dragMode            = MBIND_INVALID;
    m_exclusiveDeviceGrab = false;
    m_draggingTiled       = false;
    m_forcedGrabbedCorner.reset();
    return true;
}

void CDragStateController::mouseMove(const Vector2D& mousePos) {
    if (m_target.expired())
        return;

    const auto  DRAGGINGTARGET = m_target.lock();
    static auto PDRAGTHRESHOLD = CConfigValue<Config::INTEGER>("binds:drag_threshold");

    // Window invalid or drag begin size 0,0 meaning we rejected it.
    if ((!validMapped(DRAGGINGTARGET->window()) || m_beginDragSizeXY == Vector2D())) {
        dragEnd();
        return;
    }

    // Yoink dragged window here instead if using drag_threshold and it has been reached
    if (*PDRAGTHRESHOLD > 0 && !m_dragThresholdReached) {
        if ((m_beginDragUntransformedXY.distanceSq(Pointer::mgr()->untransformedPosition()) <= std::pow(*PDRAGTHRESHOLD, 2) && m_beginDragXY == m_lastDragXY))
            return;
        m_dragThresholdReached = true;
        if (updateDragWindow())
            return;
        m_events.motion.emit();
    }

    static auto TIMER = std::chrono::high_resolution_clock::now(), MSTIMER = TIMER;

    const auto  DELTA     = Vector2D(mousePos.x - m_beginDragXY.x, mousePos.y - m_beginDragXY.y);
    const auto  TICKDELTA = Vector2D(mousePos.x - m_lastDragXY.x, mousePos.y - m_lastDragXY.y);

    static auto SNAPENABLED = CConfigValue<Config::INTEGER>("general:snap:enabled");

    const auto  TIMERDELTA    = std::chrono::duration_cast<std::chrono::milliseconds>(std::chrono::high_resolution_clock::now() - TIMER).count();
    const auto  MSDELTA       = std::chrono::duration_cast<std::chrono::milliseconds>(std::chrono::high_resolution_clock::now() - MSTIMER).count();
    const auto  MSMONITOR     = 1000.0 / (g_pHyprRenderer->m_mostHzMonitor ? g_pHyprRenderer->m_mostHzMonitor->m_refreshRate : 60.0);
    static int  totalMs       = 0;
    bool        canSkipUpdate = true;

    MSTIMER = std::chrono::high_resolution_clock::now();

    if (m_mouseMoveEventCount == 1)
        totalMs = 0;

    if (MSMONITOR > 16.0) {
        totalMs += MSDELTA < MSMONITOR ? MSDELTA : std::round(totalMs * 1.0 / m_mouseMoveEventCount);
        m_mouseMoveEventCount += 1;

        // check if time-window is enough to skip update on 60hz monitor
        canSkipUpdate = std::clamp(MSMONITOR - TIMERDELTA, 0.0, MSMONITOR) > totalMs * 1.0 / m_mouseMoveEventCount;
    }

    if ((abs(TICKDELTA.x) < 1.f && abs(TICKDELTA.y) < 1.f) || (TIMERDELTA < MSMONITOR && canSkipUpdate && (m_dragMode != MBIND_MOVE)))
        return;

    TIMER = std::chrono::high_resolution_clock::now();

    m_lastDragXY = mousePos;

    DRAGGINGTARGET->damageEntire();

    const auto MOTIONWINDOW = DRAGGINGTARGET->window();
    const bool TRACKMOTION  = validMapped(MOTIONWINDOW);
    CBox       previousFull;

    if (TRACKMOTION)
        previousFull = MOTIONWINDOW->getFullWindowBoundingBox();

    if (m_dragMode == MBIND_MOVE) {

        Vector2D newPos  = mousePos - m_dragHotspot;
        Vector2D newSize = DRAGGINGTARGET->position().size();

        if (*SNAPENABLED && !m_draggingTiled)
            g_layoutManager->performSnap(newPos, newSize, DRAGGINGTARGET, MBIND_MOVE, -1, m_beginDragSizeXY);

        newPos = newPos.round();

        DRAGGINGTARGET->setPositionGlobal({newPos, newSize});
        DRAGGINGTARGET->warpPositionSize();
    } else if (isResizeMode(m_dragMode)) {
        if (DRAGGINGTARGET->floating()) {

            Vector2D MINSIZE = DRAGGINGTARGET->minSize().value_or(Vector2D{MIN_WINDOW_SIZE, MIN_WINDOW_SIZE});
            Vector2D MAXSIZE = DRAGGINGTARGET->maxSize().value_or(Math::VECTOR2D_MAX);

            Vector2D newSize = m_beginDragSizeXY;
            Vector2D newPos  = m_beginDragPositionXY;

            if (edgeRight(m_grabbedCorner))
                newSize.x += DELTA.x;
            else if (edgeLeft(m_grabbedCorner))
                newSize.x -= DELTA.x;

            if (edgeBottom(m_grabbedCorner))
                newSize.y += DELTA.y;
            else if (edgeTop(m_grabbedCorner))
                newSize.y -= DELTA.y;

            eMouseBindMode mode = m_dragMode;
            if (DRAGGINGTARGET->window() && DRAGGINGTARGET->window()->m_ruleApplicator->keepAspectRatio().valueOrDefault() && mode != MBIND_RESIZE_BLOCK_RATIO)
                mode = MBIND_RESIZE_FORCE_RATIO;

            if (m_beginDragSizeXY.x >= 1 && m_beginDragSizeXY.y >= 1 && mode == MBIND_RESIZE_FORCE_RATIO) {

                const float RATIO = m_beginDragSizeXY.y / m_beginDragSizeXY.x;

                if (MINSIZE.x * RATIO > MINSIZE.y)
                    MINSIZE = Vector2D(MINSIZE.x, MINSIZE.x * RATIO);
                else
                    MINSIZE = Vector2D(MINSIZE.y / RATIO, MINSIZE.y);

                if (MAXSIZE.x * RATIO < MAXSIZE.y)
                    MAXSIZE = Vector2D(MAXSIZE.x, MAXSIZE.x * RATIO);
                else
                    MAXSIZE = Vector2D(MAXSIZE.y / RATIO, MAXSIZE.y);

                if (newSize.x * RATIO > newSize.y)
                    newSize = Vector2D(newSize.x, newSize.x * RATIO);
                else
                    newSize = Vector2D(newSize.y / RATIO, newSize.y);
            }

            newSize = newSize.clamp(MINSIZE, MAXSIZE);

            if (edgeLeft(m_grabbedCorner))
                newPos.x += (m_beginDragSizeXY - newSize).x;
            if (edgeTop(m_grabbedCorner))
                newPos.y += (m_beginDragSizeXY - newSize).y;

            if (*SNAPENABLED) {
                g_layoutManager->performSnap(newPos, newSize, DRAGGINGTARGET, mode, m_grabbedCorner, m_beginDragSizeXY);
                newSize = newSize.clamp(MINSIZE, MAXSIZE);
            }

            CBox wb = {newPos, newSize};
            wb.round();

            DRAGGINGTARGET->setPositionGlobal(wb);
            DRAGGINGTARGET->warpPositionSize();
        } else {
            g_layoutManager->resizeTarget(TICKDELTA, DRAGGINGTARGET, m_grabbedCorner);
            DRAGGINGTARGET->warpPositionSize();
        }
    }

    if (TRACKMOTION)
        MOTIONWINDOW->effects().onPositionUpdate(previousFull, MOTIONWINDOW->getFullWindowBoundingBox(), Desktop::View::WINDOW_UPDATE_MOUSE);

    // get middle point
    Vector2D middle = DRAGGINGTARGET->position().middle();

    // and check its monitor
    const auto PMONITOR = State::monitorState()->query().vec(middle).run();

    if (PMONITOR && PMONITOR->m_activeWorkspace && DRAGGINGTARGET->floating() /* If we're resizing a tiled target, don't do this */) {
        const auto WS = PMONITOR->m_activeSpecialWorkspace ? PMONITOR->m_activeSpecialWorkspace : PMONITOR->m_activeWorkspace;
        DRAGGINGTARGET->assignToSpace(WS->space());
    }

    DRAGGINGTARGET->damageEntire();
    m_events.motion.emit();
}

CLayoutManager::CLayoutManager() = default;

void CLayoutManager::newTarget(SP<ITarget> target, SP<CSpace> space) {
    // on a new target: remember desired pos for float, if available
    if (const auto DESIRED_GEOM = target->desiredGeometry(); DESIRED_GEOM)
        target->rememberFloatingSize(DESIRED_GEOM->size);

    target->assignToSpace(space);
}

void CLayoutManager::removeTarget(SP<ITarget> target) {
    target->assignToSpace(nullptr);
}

void CLayoutManager::changeFloatingMode(SP<ITarget> target) {
    if (!target->space())
        return;

    auto pastFsMode = Fullscreen::FSMODE_NONE;
    // If changing floating state of grouped window, unFS then re-FS to properly apply floating related properties
    if (Fullscreen::controller()->isFullscreen(target->window())) {
        pastFsMode = Fullscreen::controller()->getFullscreenModes(target->window()).internal;
        Fullscreen::controller()->setFullscreenMode(target->window(), Fullscreen::FSMODE_NONE);
    }

    target->space()->toggleTargetFloating(target);

    if (pastFsMode != Fullscreen::FSMODE_NONE)
        Fullscreen::controller()->setFullscreenMode(target->window(), pastFsMode);

    IPC::Socket2::sock()->postEvent({
        .event = "changefloatingmode",
        .data  = std::format("{:x},{}", rc<uintptr_t>(target->window().get()), sc<int>(target->floating())),
    });
    Event::bus()->m_events.window.floating.emit(target->window());
}

void CLayoutManager::beginDragTarget(SP<ITarget> target, eMouseBindMode mode, std::optional<eRectCorner> forcedEdge, bool exclusiveDeviceGrab) {
    m_dragStateController->dragBegin(target, mode, forcedEdge, exclusiveDeviceGrab);
}

void CLayoutManager::moveMouse(const Vector2D& mousePos) {
    m_dragStateController->mouseMove(mousePos);
}

void CLayoutManager::resizeTarget(const Vector2D& Δ, SP<ITarget> target, eRectCorner corner) {
    if (target->isPseudo()) {
        auto fixedΔ = Δ;
        if (edgeLeft(corner))
            fixedΔ.x = -fixedΔ.x;
        if (edgeTop(corner))
            fixedΔ.y = -fixedΔ.y;

        auto       newPseudoSize    = target->pseudoSize() + fixedΔ;
        const auto TARGET_TILE_SIZE = target->position().size();
        newPseudoSize.x             = std::clamp(newPseudoSize.x, MIN_WINDOW_SIZE, TARGET_TILE_SIZE.x);
        newPseudoSize.y             = std::clamp(newPseudoSize.y, MIN_WINDOW_SIZE, TARGET_TILE_SIZE.y);

        target->setPseudoSize(newPseudoSize);

        return;
    }

    target->space()->resizeTarget(Δ, target, corner);
}

void CLayoutManager::setTargetGeom(const CBox& box, SP<ITarget> target) {
    if (!target->floating())
        return;

    target->space()->setTargetGeom(box, target);
}

Config::ErrorResult CLayoutManager::layoutMsg(const std::string_view& sv) {

    const auto MONITOR = Desktop::focusState()->monitor();
    // forward to the active workspace
    if (!MONITOR)
        return Config::configError("No monitor, can't find ws to target", Config::eConfigErrorLevel::ERROR, Config::eConfigErrorCode::NO_TARGET);

    auto ws = MONITOR->m_activeSpecialWorkspace ? MONITOR->m_activeSpecialWorkspace : MONITOR->m_activeWorkspace;

    if (!ws)
        return Config::configError("No workspace, can't target", Config::eConfigErrorLevel::ERROR, Config::eConfigErrorCode::NO_TARGET);

    return ws->space()->layoutMsg(sv);
}

void CLayoutManager::moveTarget(const Vector2D& Δ, SP<ITarget> target) {
    if (!target->floating())
        return;

    target->space()->moveTarget(Δ, target);
}

bool CLayoutManager::endDragTarget() {
    return m_dragStateController->dragEnd();
}

void CLayoutManager::switchTargets(SP<ITarget> a, SP<ITarget> b, bool preserveFocus) {

    if (preserveFocus) {
        a->swap(b);
        return;
    }

    const auto IS_A_ACTIVE = Desktop::focusState()->window() == a->window();
    const auto IS_B_ACTIVE = Desktop::focusState()->window() == b->window();

    a->swap(b);

    if (IS_A_ACTIVE && b->window())
        Desktop::focusState()->fullWindowFocus(b->window(), Desktop::FOCUS_REASON_KEYBIND);

    if (IS_B_ACTIVE && a->window())
        Desktop::focusState()->fullWindowFocus(a->window(), Desktop::FOCUS_REASON_KEYBIND);
}

void CLayoutManager::moveInDirection(SP<ITarget> target, const std::string& direction, bool silent) {
    Math::eDirection dir = Math::fromChar(direction.at(0));
    if (dir == Math::DIRECTION_DEFAULT) {
        LOG(Log::ERR, "invalid direction for moveInDirection: {}", direction);
        return;
    }

    if (!target->space())
        return;

    target->space()->moveTargetInDirection(target, dir, silent);
}

SP<ITarget> CLayoutManager::getNextCandidate(SP<CSpace> space, SP<ITarget> from) {
    return space->getNextCandidate(from);
}

bool CLayoutManager::isReachable(SP<ITarget> target) {
    return true;
}

void CLayoutManager::bringTargetToTop(SP<ITarget> target) {
    if (!target)
        return;

    if (target->window()->grouping().group()) {
        // grouped, change the current to this window
        target->window()->grouping().group()->setCurrent(target->window());
    }
}

std::optional<Vector2D> CLayoutManager::predictSizeForNewTiledTarget() {
    const auto FOCUSED_MON = Desktop::focusState()->monitor();

    if (!FOCUSED_MON || !FOCUSED_MON->m_activeWorkspace)
        return std::nullopt;

    if (FOCUSED_MON->m_activeSpecialWorkspace)
        return FOCUSED_MON->m_activeSpecialWorkspace->space()->predictSizeForNewTiledTarget();

    return FOCUSED_MON->m_activeWorkspace->space()->predictSizeForNewTiledTarget();
}

const UP<Supplementary::CDragStateController>& CLayoutManager::dragController() {
    return m_dragStateController;
}

static inline bool canSnap(const double SIDEA, const double SIDEB, const double GAP) {
    return std::abs(SIDEA - SIDEB) < GAP;
}

static void snapMove(double& start, double& end, const double P) {
    end   = P + (end - start);
    start = P;
}

static void snapResize(double& start, double& end, const double P) {
    start = P;
}

using SnapFn = std::function<void(double&, double&, const double)>;

void CLayoutManager::performSnap(Vector2D& sourcePos, Vector2D& sourceSize, SP<ITarget> DRAGGINGTARGET, const eMouseBindMode MODE, const int CORNER, const Vector2D& BEGINSIZE) {

    const auto DRAGGINGWINDOW = DRAGGINGTARGET->window();

    if (!Desktop::View::validMapped(DRAGGINGWINDOW))
        return;

    static auto  SNAPWINDOWGAP     = CConfigValue<Config::INTEGER>("general:snap:window_gap");
    static auto  SNAPMONITORGAP    = CConfigValue<Config::INTEGER>("general:snap:monitor_gap");
    static auto  SNAPBORDEROVERLAP = CConfigValue<Config::INTEGER>("general:snap:border_overlap");
    static auto  SNAPRESPECTGAPS   = CConfigValue<Config::INTEGER>("general:snap:respect_gaps");

    static auto  PGAPSIN  = CConfigValue<Config::IComplexConfigValue>("general:gaps_in");
    static auto  PGAPSOUT = CConfigValue<Config::IComplexConfigValue>("general:gaps_out");
    const auto   GAPSNONE = Config::CCssGapData{0, 0, 0, 0};

    const SnapFn SNAP  = (MODE == MBIND_MOVE) ? snapMove : snapResize;
    int          snaps = 0;

    struct SRange {
        double start = 0;
        double end   = 0;
    };
    const auto EXTENTS = DRAGGINGWINDOW->getWindowExtentsUnified(Desktop::View::RESERVED_EXTENTS | Desktop::View::INPUT_EXTENTS);
    SRange     sourceX = {sourcePos.x - EXTENTS.topLeft.x, sourcePos.x + sourceSize.x + EXTENTS.bottomRight.x};
    SRange     sourceY = {sourcePos.y - EXTENTS.topLeft.y, sourcePos.y + sourceSize.y + EXTENTS.bottomRight.y};

    if (*SNAPWINDOWGAP) {
        const double GAPSIZE       = *SNAPWINDOWGAP;
        const auto   WORKSPACE     = DRAGGINGWINDOW->m_workspace;
        const bool   HASFULLSCREEN = DRAGGINGWINDOW->m_workspace && Fullscreen::controller()->hasFullscreen(DRAGGINGWINDOW->m_workspace);

        const auto*  GAPSIN = *SNAPRESPECTGAPS ? sc<Config::CCssGapData*>(PGAPSIN.ptr()) : &GAPSNONE;
        const double GAPSX  = GAPSIN->m_left + GAPSIN->m_right;
        const double GAPSY  = GAPSIN->m_top + GAPSIN->m_bottom;

        for (auto& other : Desktop::windowState()->windows()) {
            if ((HASFULLSCREEN && !other->isAllowedOverFullscreen()) || other == DRAGGINGWINDOW || other->m_workspace != WORKSPACE || !other->mapped() ||
                other->backend().traits().overrideRedirect)
                continue;

            const CBox   SURF   = other->getWindowBoxUnified(Desktop::View::RESERVED_EXTENTS);
            const SRange SURFBX = {SURF.x - GAPSX, SURF.x + SURF.w + GAPSX};
            const SRange SURFBY = {SURF.y - GAPSY, SURF.y + SURF.h + GAPSY};

            // only snap windows if their ranges overlap in the opposite axis
            if (sourceY.start <= SURFBY.end && SURFBY.start <= sourceY.end) {
                if (edgeLeft(CORNER) && canSnap(sourceX.start, SURFBX.end, GAPSIZE)) {
                    SNAP(sourceX.start, sourceX.end, SURFBX.end);
                    snaps |= SNAP_LEFT;
                } else if (edgeRight(CORNER) && canSnap(sourceX.end, SURFBX.start, GAPSIZE)) {
                    SNAP(sourceX.end, sourceX.start, SURFBX.start);
                    snaps |= SNAP_RIGHT;
                }
            }
            if (sourceX.start <= SURFBX.end && SURFBX.start <= sourceX.end) {
                if (edgeTop(CORNER) && canSnap(sourceY.start, SURFBY.end, GAPSIZE)) {
                    SNAP(sourceY.start, sourceY.end, SURFBY.end);
                    snaps |= SNAP_UP;
                } else if (edgeBottom(CORNER) && canSnap(sourceY.end, SURFBY.start, GAPSIZE)) {
                    SNAP(sourceY.end, sourceY.start, SURFBY.start);
                    snaps |= SNAP_DOWN;
                }
            }

            // corner snapping
            if (sourceX.start == SURFBX.end || SURFBX.start == sourceX.end) {
                const SRange SURFY = {SURFBY.start + GAPSY, SURFBY.end - GAPSY};
                if (edgeTop(CORNER) && !(snaps & SNAP_UP) && canSnap(sourceY.start, SURFY.start, GAPSIZE)) {
                    SNAP(sourceY.start, sourceY.end, SURFY.start);
                    snaps |= SNAP_UP;
                } else if (edgeBottom(CORNER) && !(snaps & SNAP_DOWN) && canSnap(sourceY.end, SURFY.end, GAPSIZE)) {
                    SNAP(sourceY.end, sourceY.start, SURFY.end);
                    snaps |= SNAP_DOWN;
                }
            }
            if (sourceY.start == SURFBY.end || SURFBY.start == sourceY.end) {
                const SRange SURFX = {SURFBX.start + GAPSX, SURFBX.end - GAPSX};
                if (edgeLeft(CORNER) && !(snaps & SNAP_LEFT) && canSnap(sourceX.start, SURFX.start, GAPSIZE)) {
                    SNAP(sourceX.start, sourceX.end, SURFX.start);
                    snaps |= SNAP_LEFT;
                } else if (edgeRight(CORNER) && !(snaps & SNAP_RIGHT) && canSnap(sourceX.end, SURFX.end, GAPSIZE)) {
                    SNAP(sourceX.end, sourceX.start, SURFX.end);
                    snaps |= SNAP_RIGHT;
                }
            }
        }
    }

    if (*SNAPMONITORGAP) {
        const double GAPSIZE    = *SNAPMONITORGAP;
        const auto   EXTENTNONE = SBoxExtents{{0, 0}, {0, 0}};
        const auto*  EXTENTDIFF = *SNAPBORDEROVERLAP ? &EXTENTS : &EXTENTNONE;
        const auto   MON        = DRAGGINGWINDOW->m_monitor.lock();

        const auto*  GAPSOUT   = *SNAPRESPECTGAPS ? sc<Config::CCssGapData*>(PGAPSOUT.ptr()) : &GAPSNONE;
        const auto   WORK_AREA = Desktop::CReservedArea{GAPSOUT->m_top, GAPSOUT->m_right, GAPSOUT->m_bottom, GAPSOUT->m_left}.apply(MON->logicalBoxMinusReserved());

        SRange       monX = {WORK_AREA.x, WORK_AREA.x + WORK_AREA.w};
        SRange       monY = {WORK_AREA.y, WORK_AREA.y + WORK_AREA.h};

        const bool   HAS_LEFT   = MON->m_reservedArea.left() > 0;
        const bool   HAS_TOP    = MON->m_reservedArea.top() > 0;
        const bool   HAS_BOTTOM = MON->m_reservedArea.bottom() > 0;
        const bool   HAS_RIGHT  = MON->m_reservedArea.right() > 0;

        if (edgeLeft(CORNER) &&
            ((HAS_LEFT && canSnap(sourceX.start, monX.start, GAPSIZE)) || canSnap(sourceX.start, (monX.start -= MON->m_reservedArea.left() + EXTENTDIFF->topLeft.x), GAPSIZE))) {
            SNAP(sourceX.start, sourceX.end, monX.start);
            snaps |= SNAP_LEFT;
        }
        if (edgeRight(CORNER) &&
            ((HAS_RIGHT && canSnap(sourceX.end, monX.end, GAPSIZE)) || canSnap(sourceX.end, (monX.end += MON->m_reservedArea.right() + EXTENTDIFF->bottomRight.x), GAPSIZE))) {
            SNAP(sourceX.end, sourceX.start, monX.end);
            snaps |= SNAP_RIGHT;
        }
        if (edgeTop(CORNER) &&
            ((HAS_TOP && canSnap(sourceY.start, monY.start, GAPSIZE)) || canSnap(sourceY.start, (monY.start -= MON->m_reservedArea.top() + EXTENTDIFF->topLeft.y), GAPSIZE))) {
            SNAP(sourceY.start, sourceY.end, monY.start);
            snaps |= SNAP_UP;
        }
        if (edgeBottom(CORNER) &&
            ((HAS_BOTTOM && canSnap(sourceY.end, monY.end, GAPSIZE)) || canSnap(sourceY.end, (monY.end += MON->m_reservedArea.bottom() + EXTENTDIFF->bottomRight.y), GAPSIZE))) {
            SNAP(sourceY.end, sourceY.start, monY.end);
            snaps |= SNAP_DOWN;
        }
    }

    // remove extents from main surface
    sourceX = {sourceX.start + EXTENTS.topLeft.x, sourceX.end - EXTENTS.bottomRight.x};
    sourceY = {sourceY.start + EXTENTS.topLeft.y, sourceY.end - EXTENTS.bottomRight.y};

    if (MODE == MBIND_RESIZE_FORCE_RATIO) {
        if ((edgeLeft(CORNER) && snaps & SNAP_LEFT) || (edgeRight(CORNER) && snaps & SNAP_RIGHT)) {
            const double SIZEY = (sourceX.end - sourceX.start) * (BEGINSIZE.y / BEGINSIZE.x);
            if (edgeTop(CORNER))
                sourceY.start = sourceY.end - SIZEY;
            else
                sourceY.end = sourceY.start + SIZEY;
        } else if ((edgeTop(CORNER) && snaps & SNAP_UP) || (edgeBottom(CORNER) && snaps & SNAP_DOWN)) {
            const double SIZEX = (sourceY.end - sourceY.start) * (BEGINSIZE.x / BEGINSIZE.y);
            if (edgeLeft(CORNER))
                sourceX.start = sourceX.end - SIZEX;
            else
                sourceX.end = sourceX.start + SIZEX;
        }
    }

    sourcePos  = {sourceX.start, sourceY.start};
    sourceSize = {sourceX.end - sourceX.start, sourceY.end - sourceY.start};
}

void CLayoutManager::recalculateMonitor(PHLMONITOR m, eRecalculateMonitorReason reason) {
    if (m->m_activeSpecialWorkspace)
        m->m_activeSpecialWorkspace->space()->recalculate(recalcMonitorReasonToRecalcReason(reason));

    if (m->m_activeWorkspace)
        m->m_activeWorkspace->space()->recalculate(recalcMonitorReasonToRecalcReason(reason));
}

void CLayoutManager::invalidateMonitorGeometries(PHLMONITOR m) {
    for (const auto& ws : State::Workspace::state()->workspaces()) {
        if (ws && ws->m_monitor == m) {
            const auto& SPACE = ws->space();
            SPACE->recheckWorkArea();
            SPACE->recalculate(RECALCULATE_REASON_INVALIDATE_MONITOR_GEOMETRIES);
        }
    }
}

#include "hyprutils/memory/SharedPtr.hpp"
#include <hyprutils/signal/Signal.hpp>
#include <hyprutils/memory/WeakPtr.hpp>
#include <algorithm>

using namespace Hyprutils::Signal;
using namespace Hyprutils::Memory;

#define SP CSharedPointer
#define WP CWeakPointer

void Hyprutils::Signal::CSignalBase::emitInternal(void* args) {

    // Save, an event can destroy thisptr
    const auto STATICS = m_vStaticListeners;

    if (!m_vListeners.empty()) {
        std::vector<SP<CSignalListener>> listeners;
        listeners.reserve(m_vListeners.size());

        for (const auto& l : m_vListeners) {
            if (l.expired())
                continue;

            listeners.emplace_back(l.lock());
        }

        for (const auto& l : listeners) {
            // if there is only one lock, it means the event is only held by the listeners
            // vector and was removed during our iteration
            if (l.strongRef() == 1)
                continue;

            l->emitInternal(args);
        }

        // release SPs
        listeners.clear();
    }

    if (!STATICS.empty()) {
        for (const auto& l : STATICS) {
            l->emitInternal(args);
        }
    }

    // we cannot release any expired refs here as one of the listeners could've removed this object and
    // as such we'd be doing a UAF
}

CHyprSignalListener Hyprutils::Signal::CSignalBase::registerListenerInternal(std::function<void(void*)> handler) {
    CHyprSignalListener listener = SP<CSignalListener>(new CSignalListener(handler));
    m_vListeners.emplace_back(listener);

    // housekeeping: remove any stale listeners
    std::erase_if(m_vListeners, [](const auto& other) { return other.expired(); });

    return listener;
}

void Hyprutils::Signal::CSignalBase::registerStaticListenerInternal(std::function<void(void*)> handler) {
    m_vStaticListeners.emplace_back(SP<CSignalListener>(new CSignalListener(handler)));
}

void Hyprutils::Signal::CSignal::emit(std::any data) {
    CSignalT::emit(data);
}

#include <hyprutils/signal/Listener.hpp>
#include <tuple>

using namespace Hyprutils::Signal;

Hyprutils::Signal::CSignalListener::CSignalListener(std::function<void(void*)> handler) : m_fHandler(handler) {
    ;
}

void Hyprutils::Signal::CSignalListener::emitInternal(void* data) {
    if (!m_fHandler)
        return;

    m_fHandler(data);
}

void Hyprutils::Signal::CSignalListener::emit(std::any data) {
    auto dataTuple = std::tuple<std::any>(data);
    emitInternal(&dataTuple);
}
