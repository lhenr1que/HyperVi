## 2. `changeMouseBindMode`, `dragBegin`, `dragEnd`, `exclusiveDeviceGrab`

**Corpo antigo** (`O:KeybindManager.cpp:949–975`): `MODE != INVALID` → retorna se já há alvo; `windowAt(cursor, RESERVED_EXTENTS|INPUT_EXTENTS|ALLOW_FLOATING)`; sem janela → `passEvent`; se não-fullscreen e `MOVE`, `checkInputOnDecos(DRAG_START)` pode recusar; `beginDragTarget(PWINDOW->layoutTarget(), MODE)`. `MODE == INVALID` → `endDragTarget()` se há alvo. O valor de retorno é ignorado em **todas** as chamadas do plugin.

**Candidato 0.57** (compila na sonda K como função **não integrada** `candidateChangeMouseBindMode`): o mesmo corpo sobre `Desktop::viewState()->hitTest().windowAt(...)`, `Fullscreen::controller()->isFullscreen`, `presentation().checkInputOnDecorations(INPUT_TYPE_DRAG_START, …)`, `g_layoutManager->beginDragTarget(…, MODE)` (defaults: `forcedEdge = nullopt`, `exclusiveDeviceGrab = false`, como antes) e `endDragTarget()` com a mesma guarda. `U:ConfigActions.cpp:1695–1738` (`Actions::mouse`) tem o mesmo corpo, mas decide início/fim por `Config::Actions::state()->m_passPressed` (estado global de bind) → **não usar** fora de um bind.

## 5. Q4 — restauração de estado no descarregamento (proposta, não implementada)

Hoje `PLUGIN_EXIT` (`main.cpp:526–542`) **não** encerra drag/grab iniciado pelo plugin (L17, `LEDGER.md:45`; `QUIESCENCE.md:30`). Proposta para o passo 2 do protocolo de unload (mudança de **lifecycle**, autorização própria):

1. Registrar no plugin, ao iniciar (K1/K2), o alvo do drag: `WP<Layout::ITarget> ownedDrag = g_layoutManager->dragController()->target()`, logo após `beginDragTarget` (pode ser nulo: `dragBegin` pode recusar).
2. No passo 2: `if (const auto T = g_layoutManager->dragController()->target(); T && T == ownedDrag.lock()) g_layoutManager->endDragTarget();` e zerar flags (`m_bDraggingThis`, `grabActive`, `grabSwallowPress`, `m_unsnapAnim`, …).
3. **Por que não só pelas flags:** o host encerra drags sozinho a cada tecla/botão (§2); as flags do plugin podem ficar velhas e, depois, um drag iniciado por bind do usuário seria encerrado pelo unload (viola "um arrastar iniciado por atalho do usuário não é nosso", `QUIESCENCE.md:30`).
4. `endDragTarget()` no unload executa código do host (foco, `setTargetGeom`, agrupamento, `m_events.ended`); nenhum ouvinte do plugin existe em `ended` → nenhum retorno ao módulo, condição de Q3. Deve rodar **antes** de remover decorações e timers.

Testes Q4: B1-D3 aninhado — unload com (a) drag pela barra ativo, (b) grab do menu ativo, (c) unsnap em animação, (d) drag por bind do usuário ativo (não pode ser encerrado), (e) drag já encerrado pelo host com flag velha. Critério: `dragController()->target()` vazio em (a)–(c), intacto em (d), nenhuma chamada ao módulo após o passo 8.

void CHyprBar::stepUnsnap() {
    const auto W = m_pWindow.lock();
    if (!m_unsnapAnim || !W || !m_bDraggingThis) {
        m_unsnapAnim = false;
        return;
    }
    const double   P   = std::min(1.0, std::chrono::duration<double, std::milli>(Time::steadyNow() - m_unsnapT0).count() / 140.0);
    const double   E   = 1.0 - std::pow(1.0 - P, 3.0);
    const Vector2D SZ  = m_unsnapFrom + (m_unsnapTo - m_unsnapFrom) * E;
    const auto     C   = g_pInputManager->getMouseCoordsInternal();
    const Vector2D POS = {C.x - m_unsnapRatio * SZ.x, C.y - m_unsnapGrabY};
    (void)Config::Actions::resize(SZ, false, W);
    (void)Config::Actions::move(POS, false, W);
    if (P >= 1.0) {
        m_unsnapAnim = false;
        m_dragStart  = POS;
        g_pKeybindManager->changeMouseBindMode(MBIND_INVALID);
        g_pKeybindManager->changeMouseBindMode(MBIND_MOVE);
    }
}

void CHyprBar::handleUpEvent(Event::SCallbackInfo& info) {
    if (m_pWindow.lock() != Desktop::focusState()->window()) {
        // focus moved between the press and the release (e.g. the minimize button): clear the drag state instead of leaving it
        // stuck, which swallowed the next release and could start a drag with no button down
        if (m_bDraggingThis)
            g_pKeybindManager->changeMouseBindMode(MBIND_INVALID);
        m_bDraggingThis  = false;
        m_bCancelledDown = false;
        m_bDragPending   = false;
        m_bTouchEv       = false;
        m_touchId        = 0;
        return;
    }

    if (m_bCancelledDown)
        info.cancelled = true;

    m_bCancelledDown = false;

    if (m_bDraggingThis) {
        if (m_unsnapAnim) {
            m_unsnapT0 = Time::steadyNow() - std::chrono::seconds(1); // released mid-ease: land on the final size
            stepUnsnap();
        }
        g_pKeybindManager->changeMouseBindMode(MBIND_INVALID);
        m_bDraggingThis = false;
        if (m_bTouchEv)
            (void)Config::Actions::floatWindow(Config::Actions::eTogglableAction::TOGGLE_ACTION_DISABLE);
        else
            snapOnRelease();

        Log::logger->log(Log::DEBUG, "kwinish-bars", "Dragging ended on {:x}", (uintptr_t)m_pWindow.lock().get());
    }

    m_bDragPending = false;
    m_bTouchEv     = false;
    m_touchId      = 0;
}

void CHyprBar::handleMovement() {
    m_bUnsnapChecked = false;
    m_unsnapAnim     = false;
    m_resistPush     = 0;
    if (const auto W = m_pWindow.lock()) {
        m_dragStart = W->position(Desktop::View::IGeometric::GEOMETRIC_CURRENT);
        // The compositor drags the focused window. With follow_mouse, a fast move off the bar onto another window
        // can hand focus to that window before this runs, and the drag would grab it instead (a tiled window then
        // floats and follows the pointer). Pin the focus on this bar's window.
        if (Desktop::focusState()->window() != W)
            Desktop::focusState()->fullWindowFocus(W, Desktop::FOCUS_REASON_CLICK);
    }
    g_pKeybindManager->changeMouseBindMode(MBIND_MOVE);
    m_bDraggingThis = true;
    warnIfNoCore();
    Log::logger->log(Log::DEBUG, "kwinish-bars", "Dragging initiated on {:x}", (uintptr_t)m_pWindow.lock().get());
    return;
}

// O:managers/KeybindManager.cpp:949
SDispatchResult CKeybindManager::changeMouseBindMode(const eMouseBindMode MODE) {
    if (MODE != MBIND_INVALID) {
        if (g_layoutManager->dragController()->target())
            return {};

        const auto      MOUSECOORDS = g_pInputManager->getMouseCoordsInternal();
        const PHLWINDOW PWINDOW =
            Desktop::viewState()->hitTest().windowAt(MOUSECOORDS, Desktop::View::RESERVED_EXTENTS | Desktop::View::INPUT_EXTENTS | Desktop::View::ALLOW_FLOATING);

        if (!PWINDOW)
            return SDispatchResult{.passEvent = true};

        if (!Fullscreen::controller()->isFullscreen(PWINDOW) && MODE == MBIND_MOVE) {
            if (PWINDOW->checkInputOnDecos(INPUT_TYPE_DRAG_START, MOUSECOORDS))
                return SDispatchResult{.passEvent = false};
        }

        g_layoutManager->beginDragTarget(PWINDOW->layoutTarget(), MODE);
    } else {
        if (!g_layoutManager->dragController()->target())
            return {};

        g_layoutManager->endDragTarget();
    }

    return {};
}
