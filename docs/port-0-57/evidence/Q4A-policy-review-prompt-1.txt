## 3. Política candidata `veto` (Etapa 2)

Posse só é usada se **todas** valerem no instante do fim (código em `policies.hpp`, `PolVeto`):

- **(a) Aquisição verificável:** o `beginDragTarget` do **próprio** plugin rodou (resultado do helper `STARTED`, não `REFUSED_BY_DECO`), nenhum `ended` chegou durante o início e o alvo depois é o pedido. Guarda RAII `inBegin`.
- **(b) Invalidação:** ouvinte por aquisição com **token** capturado; qualquer `ended` com token atual zera a posse e solta o ouvinte; callbacks antigos (snapshots aninhados) são ignorados.
- **(c)** alvo adquirido vivo e igual a `target()`.
- **(d) Veto de transição ambígua:** `wasDraggingWindow()` verdadeiro ⇒ não encerra **e** não inicia.
- **(e) Transação não reentrante:** sem fim/início do plugin em andamento; posse **consumida antes** de `endDragTarget()`.
- **Rearm** = fim bem-sucedido seguido de novo início com nova aquisição. **Unload passo 2** = `unloading`, fim se (a)–(e), solta ouvinte sempre.

Nenhum item usa alvo, modo, geração ou flag local isoladamente como prova: alvo só vale junto de (a)+(b); a geração/token só invalida; `wasDraggingWindow` só **veta**. Flags do plugin (`m_bDraggingThis`, `grabActive`) não entram na posse.

**Argumento de segurança (mundo fechado).** Suponha um fim do Kwinish sobre sessão S de terceiro com (a)–(e) válidos. Pela guarda A3 do chamador de S, `target()` estava nulo quando S começou, logo a sessão do plugin terminou depois da aquisição por um `dragEnd` (alvo vivo ⇒ `ended` emitido na saída) ou o alvo expirou (viola (c)). Se aquele `dragEnd` já terminou, o ouvinte (registrado antes dele) recebeu `ended` ⇒ (b) falso. Logo o fim do Kwinish ocorreu **dentro** desse `dragEnd`: W1/W3/W4 não têm código estranho; W2 é vetada por (d); resta W5 antes do ouvinte do Kwinish, o que exige um ouvinte estranho de `ended` (inexistente no host). Se o fim originou-se no próprio Kwinish, (e) bloqueia também W5.

**Premissas:** A1 thread única; A3 todo chamador de `dragBegin` checa `target()` (host verificado; terceiros: premissa); A4 `ended` síncrono e único por fim com alvo vivo; A5 unload fora de emissões; **D1 (nova, não aceita):** nenhum ouvinte de `ended` de terceiros, anterior ao do Kwinish, reinicia drag e alcança sincronamente uma entrada de fim do Kwinish; **D2:** classificação W1–W5 e escritores da flag valem só para `0aa6745f` (reverificar a cada versão).

## 6. Limitações

Réplica manual, não o host: sem hit-test, ordem real de decorações, Lua real, `updateDragWindow` completo, cancelamento de eventos de botão. Classificação das janelas é leitura estática de uma versão. Não modelados: C6 (falha de `listen`), exceções do host, *wrap* do token, rollback das flags dos chamadores quando o início é vetado (`handleMovement` marca `m_bDraggingThis` sem olhar o resultado), e o cancelamento da soltura pelo Kwinish (`handleUpEvent`): com a candidata, um drag iniciado pela **group bar** durante o início do Kwinish (`G1`) não é encerrado pelo plugin e o host só o encerra num botão **não cancelado** — risco de liveness a decidir antes de produção.

## 7. Veredito

**Q4-A continua BLOQUEADO para implementação.** Com as APIs 0.57 existentes e sem trabalho diferido ou ganchos, a política `veto` é a mais forte encontrada, mas sua garantia depende de D1 (terceiros), que não é demonstrável pelo plugin. Não declarar sucesso.

## 8. Alternativas (decisão do dono)

1. **Aceitar D1** (mesma classe de A3) e usar `veto` síncrona; documentar risco com plugins que ouvem `DragController::ended`.
2. **Fim diferido** (`doLaterLock` + cancelamento em `PLUGIN_EXIT`): fecha W5 sem novas premissas além de A3; muda a ordem dos efeitos (o fim ocorre após o restante do handler, ex. `snapOnRelease`); exige autorização de lifecycle.
3. **Ganchos de função** em `CDragStateController::dragBegin/dragEnd`: identidade real de sessão, também cobre A3; exige autorização de hook/lifecycle e verificação de que os símbolos não são *inlined*.
4. **Upstream:** id de sessão em `ended` (ou alvo), emissão antes do reset, ou guarda em `dragBegin`.
5. **Não encerrar e não cancelar a soltura sem posse** (delegar ao host): liveness pelo comportamento nativo; muda a entrega do botão ao cliente.

struct STarget {

class CHost {

            if (w->name == n) return w;
        return nullptr;

    // idle dispatch (CEventLoopManager::doLater -> wl_event_loop_add_idle). The real loop runs idle callbacks only from
    // wl_display_run (EventLoopManager.cpp:137), never from inside dragEnd or a signal emission; the model asserts it.

    void                               runIdle() {
        if (m_endDepth || m_emitDepth) { std::printf("MODEL ERROR: idle inside dragEnd/emission\n"); std::abort(); }
        while (!idleQueue.empty()) {
            auto q = std::move(idleQueue);
            idleQueue.clear();
            for (auto& f : q) f();
        }
    }

    // caller attribution (truth)
    struct CallerScope {
        CHost& h;
        CallerScope(CHost& h_, eWho w) : h(h_) { h.m_callers.push_back(w); }
        ~CallerScope() { h.m_callers.pop_back(); }

  private:
    // =========================== HOST STATE (private in 0.57) ===========================================
    WPT   m_target;
    eMode m_dragMode          = M_INVALID;

    uint64_t m_hookSeq = 0;

    void dragBegin(SPT t, eMode mode) { // U:159-251
        ++m_hookSeq;
        noteBegin(t);
        m_target   = t; // :160 (no guard)
        m_dragMode = mode;
        const auto D = m_target.lock();
        if (!D->mapped) { dragEnd(); return; }        // :174-178
        if (!D->hasWorkspace) { dragEnd(); return; }  // :180-184
        if (D->fsWorkspaceReject) { dragEnd(); return; } // :189-190 -> updateDragWindow :123-127 (mapped path)
        if (auto f = onBeginFocus) f();               // :244-247 rawWindowFocus/raise
        markClean();
    }

    bool dragEnd() { // U:252-334
        auto D = m_target.lock();
        if (!D) return false; // :255-256: no `ended`
        ++m_hookSeq;
        noteEndEntry(D);
        ++m_endDepth;

        Hyprutils::Utils::CScopeGuard notifyEnded([this] { emitEnded(); });           // :258

            if (D->hasWindow) resetTarget();                                           // :265
            m_dragMode = M_INVALID;
            return true;
        }
        resetTarget();                                                                 // :274
        m_wasDraggingWindow = true;                                                    // :275
        if (m_dragMode == M_MOVE && D->overOtherWindow) {                              // :277-286
            if (onDecoDragEnd) {
                auto f = onDecoDragEnd; // copy: a callback may clear itself
                if (f()) {                                                             // :287
                    m_wasDraggingWindow = false;                                       // :288
                    m_dragMode          = M_INVALID;                                   // :289
                    return true;                                                       // :292
                }
            }
            if (D->joinsGroup)
                if (auto f = onGroupAdd) f();                                          // :299
        }
        if (D->draggingTiled)
            if (auto f = onFloatingChange) f();                                        // :311-314
        if (auto f = onSetTargetGeom) f();                                             // :321
        if (auto f = onFocus) f();                                                     // :323
        m_wasDraggingWindow = false;                                                   // :325
        // :326-327 setClientResizingState -> XDG setResizing: only doLaterLock (XDGShell.cpp:444-498, 668-676);
        // X11Backend::setResizing is empty. No synchronous foreign code between :325 and the emission.
        m_dragMode = M_INVALID;                                                        // :329

    friend struct Truth;
    std::vector<eWho>        m_callers;
    std::vector<SSession>    m_sessions;
    std::optional<size_t>    m_cur; // session whose target is m_target (valid only while m_target is alive)
    int                      m_endDepth = 0, m_emitDepth = 0;
    uint64_t                 m_emissions = 0;
    std::vector<std::string> m_violations;
    std::vector<SEndRequest> m_requests;

    eWho caller() const { return m_callers.empty() ? W_HOST : m_callers.back(); }
    void noteBegin(const SPT& t) {
        if (caller() == W_KWINISH && m_target.lock())
            m_violations.push_back("kwinish replaced an active session (unguarded begin)");
        SSession s;
        s.id     = m_sessions.size() + 1;
        s.who    = caller();
        s.target = t->name;
        for (auto& o : m_sessions)
            if (o.who == s.who && o.target == s.target) ++s.ordinal;
        s.cleanMark = UINT64_MAX;
        m_sessions.push_back(s);
        m_cur = m_sessions.size() - 1;
    }
    void markClean() { if (m_cur) m_sessions[*m_cur].cleanMark = m_emissions; }
    void noteEndEntry(const SPT&) {
        if (!m_cur) return;
        auto& s = m_sessions[*m_cur];
        if (caller() == W_KWINISH) {
            if (s.who != W_KWINISH)
                m_violations.push_back(std::string("kwinish ended a ") + whoName(s.who) + " session on " + s.target);
            s.endedByKwinish = true;
        } else
            s.endedByOther = true;
    }
    void resetTarget() { m_target.reset(); m_cur.reset(); }
    void emitEnded() {
        ++m_emissions;
        ++m_emitDepth;
        m_events.ended.emit();
        --m_emitDepth;
    }
};

// Oracle/driver access to the truth layer. Policies must not use this.
struct Truth {
    static std::optional<SSession> current(const CHost& h) {
        if (!h.m_target.lock() || !h.m_cur) return std::nullopt;
        return h.m_sessions[*h.m_cur];
    }
    static const std::vector<SSession>&    sessions(const CHost& h) { return h.m_sessions; }
    static const std::vector<std::string>& violations(const CHost& h) { return h.m_violations; }
    static std::vector<SEndRequest>&       requests(CHost& h) { return h.m_requests; }
    static int                             endDepth(const CHost& h) { return h.m_endDepth; }
    // the live session was begun by `who`, its begin completed (no refusal) and no `ended` was emitted since
    static bool startedCleanly(const CHost& h, eWho who) {
        const auto s = current(h);
        return s && s->who == who && s->cleanMark != UINT64_MAX && s->cleanMark == h.m_emissions;
    }
    static int                             emitDepth(const CHost& h) { return h.m_emitDepth; }
    // A Kwinish end entry is "provably safe" when: no dragEnd frame and no `ended` emission is on the stack, the live
    // session was begun by Kwinish itself and no `ended` was emitted since that begin returned. Only then is ending
    // REQUIRED (liveness). Everywhere else the policy may refuse.
    static void noteEndRequest(CHost& h, const std::string& where) {
        SEndRequest r;
        r.endDepth  = h.m_endDepth;
        r.emitDepth = h.m_emitDepth;
        r.where     = where;
        if (h.m_target.lock() && h.m_cur) {
            r.session          = *h.m_cur;
            const auto& s      = h.m_sessions[*h.m_cur];
            r.livenessRequired = !r.endDepth && !r.emitDepth && s.who == W_KWINISH && s.cleanMark == h.m_emissions;
        }
        h.m_requests.push_back(r);
    }
};

enum eBeginResult { STARTED, ALREADY, REFUSED, REFUSED_BY_DECO };
inline const char* beginName(eBeginResult r) {
    static const char* N[] = {"STARTED", "ALREADY", "REFUSED", "REFUSED_BY_DECO"};
    return N[r];
}

// Production start helper (plugin/hostDrag.hpp, P8-B): refuse if any drag, ask decorations for DRAG_START, then begin.
inline eBeginResult kwDragBegin(CHost& h, SPT t, eMode m) {
    if (h.target())
        return ALREADY;
    if (m == M_MOVE && h.decorationsTakeDragStart(t))
        return REFUSED_BY_DECO;
    h.beginDragTarget(t, m);
    return STARTED;
}

struct IPolicy {
    explicit IPolicy(CHost& h_) : h(h_) {}
    virtual ~IPolicy()                              = default;
    virtual const char*  name() const               = 0;
    virtual eBeginResult begin(SPT t, eMode m)      = 0; // K1/K2
    virtual void         requestEnd()               = 0; // K3/K9
    virtual void         requestRearm(SPT t, eMode m) { requestEnd(); (void)begin(t, m); }
    virtual void         unload()                   = 0; // PLUGIN_EXIT step 2
    virtual bool         owns() const               = 0;
    CHost&               h;
};

// Counterfactual and liveness control: starts like production, never ends anything.
struct PolNone : IPolicy {
    using IPolicy::IPolicy;
    const char*  name() const override { return "none"; }
    eBeginResult begin(SPT t, eMode m) override { return kwDragBegin(h, t, m); }
    void         requestEnd() override {}
    void         requestRearm(SPT, eMode) override {}
    void         unload() override {}
    bool         owns() const override { return false; }
};

// Legacy idea: end when the current target is the one we started.
struct PolTarget : IPolicy {
    using IPolicy::IPolicy;
    WPT          remembered;
    const char*  name() const override { return "target-eq"; }
    eBeginResult begin(SPT t, eMode m) override {
        const auto r = kwDragBegin(h, t, m);
        remembered   = t;
        return r;
    }
    bool owns() const override { return h.target() && h.target() == remembered.lock(); }
    void requestEnd() override {
        if (owns())
            h.endDragTarget();
    }
    void unload() override { requestEnd(); }
};

// Previous Q4-A follow-up contract C1-C4 (session listener + generation + acquisition token + inBegin/inOwnEnd),
// acquisition by post-check target()==t. Kept to show which new scenarios it fails.
struct PolC3 : IPolicy {
    using IPolicy::IPolicy;
    uint64_t                generation = 0, acquisition = 0;
    std::optional<uint64_t> ownedAt;
    WPT                     ownedTarget;
    CHyprSignalListener     listener;
    bool                    inBegin = false, inOwnEnd = false, unloading = false;
    const char*             name() const override { return "C3-prev"; }
    void                    disarm() { ++acquisition; ownedAt.reset(); ownedTarget.reset(); listener.reset(); }
    bool owns() const override { return listener && ownedAt && *ownedAt == generation && !ownedTarget.expired() && h.target() == ownedTarget.lock(); }
    eBeginResult begin(SPT t, eMode m) override {
        if (unloading || inOwnEnd || inBegin) return REFUSED;
        if (h.target()) return ALREADY;
        inBegin = true;
        Hyprutils::Utils::CScopeGuard g([this] { inBegin = false; });
        const uint64_t tok = ++acquisition;
        listener           = h.m_events.ended.listen([this, tok] { if (tok != acquisition) return; ++generation; disarm(); });
        const uint64_t G0  = generation;
        const auto     r   = kwDragBegin(h, t, m);
        if (generation != G0 || !h.target() || h.target() != t) { disarm(); return r == STARTED ? REFUSED : r; }
        ownedAt = G0; ownedTarget = t;
        return STARTED; // NOTE: ignores r (a decoration may have started the drag on t)
    }
    void requestEnd() override {
        if (!owns()) return;
        inOwnEnd = true;
        h.endDragTarget();
        inOwnEnd = false;
        if (ownedAt) disarm();
    }
    void unload() override { unloading = true; if (owns()) requestEnd(); disarm(); }
};

// ===== CANDIDATE: verifiable ownership + ambiguity veto + consume-before-end =========================================
// Ownership proof obligations (all must hold at the instant of the end call):
//   (a) acquired only when the plugin's OWN beginDragTarget ran (helper result STARTED), no `ended` was observed
//       during the begin and the controller's target is the requested one afterwards;
//   (b) the session listener armed for that acquisition is still installed and its token is current (no `ended`
//       delivered to it since); callbacks with an old token are ignored;
//   (c) the acquired target is alive and is the controller's target;
//   (d) the host is NOT inside the mapped-window callback span of a dragEnd: wasDraggingWindow() is false
//       (U:275 sets it after the target reset, :288/:325 clear it before the emission);
//   (e) no other plugin end/begin transaction is running (non-reentrant), and ownership is CONSUMED before calling
//       endDragTarget, so nothing reached synchronously from inside that call can reuse it.
struct PolVeto : IPolicy {
    using IPolicy::IPolicy;
    uint64_t                generation = 0, acquisition = 0;
    std::optional<uint64_t> ownedAt;
    WPT                     ownedTarget;
    CHyprSignalListener     listener;
    bool                    inBegin = false, inEnd = false, unloading = false;
    int                     vetoes = 0;
    const char*             name() const override { return "veto"; }
    void                    disarm() { ++acquisition; ownedAt.reset(); ownedTarget.reset(); listener.reset(); } // veto: token + listener
    bool                    ambiguous() const { return h.wasDraggingWindow(); }
    bool                    owns() const override {
        if (!listener || !ownedAt || *ownedAt != generation) return false;     // (b)
        if (ownedTarget.expired() || h.target() != ownedTarget.lock()) return false; // (c)
        return true;
    }
    eBeginResult begin(SPT t, eMode m) override {
        if (unloading || inBegin || inEnd) return REFUSED;                 // (e)
        if (ambiguous()) { ++vetoes; return REFUSED; }                     // (d) do not start inside a host end
        if (h.target()) return ALREADY;
        inBegin = true;
        Hyprutils::Utils::CScopeGuard g([this] { inBegin = false; });
        const uint64_t tok = ++acquisition;
        listener           = h.m_events.ended.listen([this, tok] {
            if (tok != acquisition) return;                                // (b) stale snapshot callback
            ++generation;
            disarm();
        });
        const uint64_t G0 = generation;
        const auto     r  = kwDragBegin(h, t, m);
        if (r != STARTED) { disarm(); return r; }                          // (a) e.g. the group bar took the drag
        if (generation != G0 || h.target() != t) { disarm(); return REFUSED; } // (a)
        ownedAt     = G0;
        ownedTarget = t;
        return STARTED;
    }
    bool endOwned() {
        if (inEnd || inBegin) return false;                                // (e)
        if (ambiguous()) { ++vetoes; return false; }                       // (d)
        if (!owns()) return false;
        disarm();                                                          // (e) consume before the call
        inEnd = true;
        Hyprutils::Utils::CScopeGuard g([this] { inEnd = false; });
        return h.endDragTarget();
    }
    void requestEnd() override { (void)endOwned(); }
    void requestRearm(SPT t, eMode m) override {
        if (endOwned()) (void)begin(t, m);
    }
    void unload() override { unloading = true; (void)endOwned(); disarm(); }
};

// ===== ALTERNATIVE (needs deferred work = lifecycle authorization): same proof, end executed at idle ================
// End entries only RECORD the request with the current acquisition token; an idle callback (doLater) re-checks
// ownership when no dragEnd frame and no `ended` emission is on the stack, so every `ended` of a finished end has been
// delivered. Must be cancelled in PLUGIN_EXIT (removeDoLater/doLaterLock) - not authorized in this step.
struct PolDefer : PolVeto {
    using PolVeto::PolVeto;
    std::optional<uint64_t> pendingFor;
    std::optional<eMode>    pendingRearm;
    SPT                     rearmTarget;
    bool                    scheduled = false;
    const char*             name() const override { return "defer"; }
    void                    schedule() {
        if (scheduled) return;
        scheduled = true;
        h.idleQueue.push_back([this] {
            CHost::CallerScope s(h, W_KWINISH);
            scheduled      = false;
            const auto tok = pendingFor;
            const auto rm  = pendingRearm;
            auto       rt  = rearmTarget;
            pendingFor.reset(); pendingRearm.reset(); rearmTarget = nullptr;
            if (!tok || *tok != acquisition) return; // ownership changed since the request
            if (endOwned() && rm) (void)begin(rt, *rm);
        });
    }
    void requestEnd() override {
        if (unloading || !owns()) return;
        pendingFor = acquisition;
        schedule();
    }
    void requestRearm(SPT t, eMode m) override {
        if (unloading || !owns()) return;
        pendingFor = acquisition; pendingRearm = m; rearmTarget = t;
        schedule();
    }
    void unload() override { pendingFor.reset(); pendingRearm.reset(); rearmTarget = nullptr; PolVeto::unload(); }
};

// ===== ALTERNATIVE (needs function hooks on dragBegin/dragEnd = hook + lifecycle authorization) =====================
// A hook gives a real session identity: any begin or end after the acquisition changes the sequence.
struct PolHook : IPolicy {
    using IPolicy::IPolicy;
    std::optional<uint64_t> ownedSeq;
    WPT                     ownedTarget;
    bool                    inBegin = false, inEnd = false, unloading = false;
    const char*             name() const override { return "hook"; }
    bool owns() const override { return ownedSeq && *ownedSeq == h.hookSeq() && !ownedTarget.expired() && h.target() == ownedTarget.lock(); }
    eBeginResult begin(SPT t, eMode m) override {
        if (unloading || inBegin || inEnd) return REFUSED;
        if (h.target()) return ALREADY;
        inBegin = true;
        Hyprutils::Utils::CScopeGuard g([this] { inBegin = false; });
        const uint64_t S0 = h.hookSeq();
        const auto     r  = kwDragBegin(h, t, m);
        if (r != STARTED) return r;
        if (h.hookSeq() != S0 + 1 || h.target() != t) return REFUSED; // anything else began/ended meanwhile
        ownedSeq    = h.hookSeq();
        ownedTarget = t;
        return STARTED;
    }
    bool endOwned() {
        if (inEnd || inBegin || !owns()) return false;
        ownedSeq.reset();
        inEnd = true;
        Hyprutils::Utils::CScopeGuard g([this] { inEnd = false; });
        return h.endDragTarget();
    }
    void requestEnd() override { (void)endOwned(); }
    void requestRearm(SPT t, eMode m) override { if (endOwned()) (void)begin(t, m); }
    void unload() override { unloading = true; (void)endOwned(); ownedSeq.reset(); }
};

struct Ctx {

        return p.begin(t, m);

    void kwRearm(SPT t, const char* where) { // rearm entry (Shift / unsnap restart)

        Truth::noteEndRequest(h, "unload step 2");
        CHost::CallerScope s(h, W_KWINISH);
        p.unload();
    }
    void hostEnd() { // key / button / floatWindow / Actions::mouse / unmap (F7)
        CHost::CallerScope s(h, W_HOST);
        h.endDragTarget();
    }
    void guardedBegin(eWho w, SPT t, eMode m = M_MOVE) { // every 0.57 host caller checks target() first (F2/A3)
        CHost::CallerScope s(h, w);
        if (!h.target()) h.beginDragTarget(t, m);

    void foreignEnd(eWho w) {
        CHost::CallerScope s(h, w);
        h.endDragTarget();
    }
    void groupBarStart(eWho w, SPT t) { // Actions::mouse over a group bar (ConfigActions.cpp:1704,1733)
        CHost::CallerScope s(h, w);
        if (!h.target()) (void)h.decorationsTakeDragStart(t);
    }
};

    const char*                     what;

struct SFinal {
    bool        has = false;
    eWho        who = W_HOST;
    std::string target;
    int         ordinal = 0;
    eMode       mode    = M_INVALID;
    bool        wasDragging = false;
    std::string str() const {
        if (!has) return std::string("no drag") + (wasDragging ? " wasDragging=1" : "");
        return std::string(whoName(who)) + ":" + target + "#" + std::to_string(ordinal) + " mode=" + std::to_string(mode) + (wasDragging ? " wasDragging=1" : "");
    }
};
struct SResult {
    std::vector<std::string> o1, o2, o3, spec;
    std::string              orphan;
    SFinal                   fin;
    std::string              note;
};

template <typename P>
static SResult runOne(const SScenario& sc) {
    CHost h;
    P     p(h);
    Ctx   c{h, p, {}};
    sc.body(c);
    h.runIdle(); // the event loop returns to idle at the end of the scenario
    SResult r;
    r.spec = c.spec;
    // O1: no improper end/replacement requested by Kwinish (truth: caller + session initiator at the dragEnd entry)
    r.o1 = Truth::violations(h);
    // O2: every provably safe own end request was honoured (possibly at idle)
    for (const auto& q : Truth::requests(h))
        if (q.livenessRequired && q.session && !Truth::sessions(h)[*q.session].endedByKwinish)
            r.o2.push_back(std::string("own clean session not ended after request at '") + q.where + "'");
    if (auto s = Truth::current(h)) {
        r.fin = {true, s->who, s->target, s->ordinal, h.mode(), h.wasDraggingWindow()};
        if (s->who == W_KWINISH && !p.owns()) r.orphan = "kwinish session " + s->target + " alive without ownership";
    } else
        r.fin.wasDragging = h.wasDraggingWindow();
    return r;
}

// O3: compare the final host state with the counterfactual run in which Kwinish never ends anything (PolNone).
static void oracle3(SResult& r, const SResult& none) {
    const auto& P = r.fin;
    const auto& N = none.fin;
    if (P.wasDragging != N.wasDragging) r.o3.push_back("wasDraggingWindow differs from counterfactual");
    if (N.has && N.who != W_KWINISH) {
        if (!P.has || P.who != N.who || P.target != N.target || P.ordinal != N.ordinal || P.mode != N.mode)
            r.o3.push_back("foreign session " + N.str() + " (counterfactual) became " + P.str());
    } else if (!N.has && P.has && P.who != W_KWINISH)
        r.o3.push_back("foreign session " + P.str() + " exists only with the policy");
    // attribution of the final host state
    if (P.has && P.mode == M_INVALID) {
        const bool same = N.has && N.who == P.who && N.target == P.target && N.ordinal == P.ordinal && N.mode == P.mode;
        if (same)
            r.note = std::string("compositor-caused: ") + whoName(P.who) + " session left with mode INVALID by the host; identical in the run without Kwinish ends";
        else if (r.o1.empty())
            r.note = std::string("host-caused inside an end Kwinish requested for ITS OWN session: ") + whoName(P.who) +
                " session left with mode INVALID by the enclosing dragEnd (R3 host limit; O1 shows no foreign session was ended)";
        else
            r.note = "differs from the run without Kwinish ends; caused by the improper end reported by O1";
    }
}

template <typename P>
static std::map<std::string, SResult> runAll(const std::vector<SScenario>& sc, const std::map<std::string, SResult>* none) {
    std::map<std::string, SResult> out;
    for (auto& s : sc) {
        auto r = runOne<P>(s);
        if (none) oracle3(r, none->at(s.name));
        out[s.name] = r;
    }
    return out;
}

int main(int argc, char** argv) {
    const bool verbose = argc > 1 && !std::strcmp(argv[1], "-v");
    const auto sc      = scenarios();
    auto       none    = runAll<PolNone>(sc, nullptr);
    for (auto& [k, r] : none) oracle3(r, none.at(k));
    std::vector<std::pair<std::string, std::map<std::string, SResult>>> all;
    all.push_back({"none", none});
    all.push_back({"target-eq", runAll<PolTarget>(sc, &none)});
    all.push_back({"C3-prev", runAll<PolC3>(sc, &none)});
    all.push_back({"veto", runAll<PolVeto>(sc, &none)});
    all.push_back({"defer", runAll<PolDefer>(sc, &none)});
    all.push_back({"hook", runAll<PolHook>(sc, &none)});

    std::printf("%-30s", "scenario \\ policy");
    for (auto& [n, _] : all) std::printf(" %-10s", n.c_str());
    std::printf("\n");
    for (auto& s : sc) {
        std::printf("%-30s", s.name);
        for (auto& [n, m] : all) {
            const auto& r = m.at(s.name);
            std::string cell = std::string(r.o1.empty() ? "." : "1") + (r.o2.empty() ? "." : "2") + (r.o3.empty() ? "." : "3") + (r.spec.empty() ? "" : "s") + (r.orphan.empty() ? "" : "o");
            std::printf(" %-10s", cell.c_str());
        }
        std::printf("\n");
    }
    std::printf("legend: 1 = O1 improper Kwinish end, 2 = O2 safe own end not honoured, 3 = O3 final state differs from counterfactual, s = scenario contract check failed, o = Kwinish session alive without ownership (info)\n");
    // machine-readable lines + details
    for (auto& [n, m] : all)
        for (auto& s : sc) {
            const auto& r = m.at(s.name);
            std::printf("RES %s %s O1=%d O2=%d O3=%d spec=%d orphan=%d final=[%s]%s%s\n", n.c_str(), s.name, !r.o1.empty(), !r.o2.empty(), !r.o3.empty(), !r.spec.empty(), !r.orphan.empty(), r.fin.str().c_str(),
                        r.note.empty() ? "" : " NOTE: ", r.note.c_str());
            if (verbose || n == "veto" || n == "defer")
                for (auto* vec : {&r.o1, &r.o2, &r.o3, &r.spec})
                    for (auto& e : *vec) std::printf("    %s/%s: %s\n", n.c_str(), s.name, e.c_str());
        }
    return 0;
}

def build_run(src: pathlib.Path, cxx: str, tag: str):
    exe = SCRATCH / f"t-{tag}-{cxx}"
    b = subprocess.run([cxx, "-std=c++2b", "-Wall", "-Wextra", "-Werror", "-g", "-fsanitize=address,undefined", "-fno-sanitize-recover=all",
                        str(src / "policytest.cpp"), "-o", str(exe), *HU], capture_output=True, text=True, env=ENV)
    if b.returncode:
        return b.returncode, None, b.stdout + b.stderr
    r = subprocess.run([str(exe)], capture_output=True, text=True, env=ENV, timeout=120)
    return 0, r, ""


def matrix(out: str):
    lines = out.splitlines()
    start = next(i for i, l in enumerate(lines) if l.startswith("scenario \\ policy"))
    end = next(i for i, l in enumerate(lines) if l.startswith("legend:"))
    head = lines[start].split()[3:]
    m = {}
    for l in lines[start + 1:end]:
        f = l.split()
        for pol, cell in zip(head, f[1:]):
            m[(f[0], pol)] = cell
    return lines[start:end + 1], m

print("RESULT:", "FAIL" if fail else "PASS (matrix reproduced; see VERDICT lines - this is not an approval)")
sys.exit(1 if fail else 0)

    enum eBeginResult : uint8_t {
        BEGIN_STARTED = 0,      // beginDragTarget was called (the host may still refuse inside it)
        BEGIN_ALREADY_DRAGGING, // a drag was in progress: left untouched
        BEGIN_NO_WINDOW,        // nothing under the pointer (0.56.2: passEvent)
        BEGIN_REFUSED_BY_DECO,  // a decoration took the drag start (0.56.2: passEvent = false)
        BEGIN_BAD_MODE,         // not MBIND_MOVE / MBIND_RESIZE: nothing done
    };

    // MODE must be MBIND_MOVE or MBIND_RESIZE; anything else does nothing (0.56.2 ended the drag for MBIND_INVALID,
    // which this helper deliberately does not do).
    inline eBeginResult begin(eMouseBindMode MODE) {
        if (MODE != MBIND_MOVE && MODE != MBIND_RESIZE)
            return BEGIN_BAD_MODE;
        if (g_layoutManager->dragController()->target())
            return BEGIN_ALREADY_DRAGGING;

        const auto      MOUSECOORDS = g_pInputManager->getMouseCoordsInternal();
        const PHLWINDOW PWINDOW =
            Desktop::viewState()->hitTest().windowAt(MOUSECOORDS, Desktop::View::RESERVED_EXTENTS | Desktop::View::INPUT_EXTENTS | Desktop::View::ALLOW_FLOATING);

        if (!PWINDOW)
            return BEGIN_NO_WINDOW;

        if (!Fullscreen::controller()->isFullscreen(PWINDOW) && MODE == MBIND_MOVE) {
            if (PWINDOW->presentation().checkInputOnDecorations(INPUT_TYPE_DRAG_START, MOUSECOORDS))
                return BEGIN_REFUSED_BY_DECO;
        }

        g_layoutManager->beginDragTarget(PWINDOW->layoutTarget(), MODE);
        return BEGIN_STARTED;
