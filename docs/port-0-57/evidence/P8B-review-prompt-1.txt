## 2. Bloqueio de K3/K9 (e do rearm)

API 0.57 do drag (`H:layout/supplementary/DragController.hpp`): públicos só `target()`, `mode()`, `wasDraggingWindow()`, `dragThresholdReached()`, `draggingTiled()`, `exclusiveDeviceGrab()` e os sinais `m_events.{motion,ended}`; posição inicial, hotspot, contadores etc. são **privados**. `endDragTarget()` devolve só "havia alvo". **Não há identificador de sessão.** A única invalidação por sessão é o sinal `ended`, que exige um ouvinte — o desenho de posse por sessão de P7 §5 (geração + `ended`), que pertence a Q4 (ouvinte com vida ligada ao unload, reentrada durante `dragEnd`).

Demonstração (host falso, `evidence/P8B-equiv.txt`, modo `blocker`): a barra inicia um drag na janela A; o host o encerra numa tecla (a flag `m_bDraggingThis` do plugin continua `true`, como hoje); um atalho do usuário inicia outro drag na **mesma** A; a barra solta o botão e tenta encerrar "o seu". Os três candidatos sem posse encerram o drag do usuário: (1) incondicional (semântica 0.56.2 de `changeMouseBindMode(INVALID)`), (2) `target() == alvo lembrado`, (3) `target() == alvo lembrado && mode() == MOVE` → **3/3 UNSAFE**. Rearm só com `begin`: com o próprio drag ativo, `begin` devolve `BEGIN_ALREADY_DRAGGING` e não reinicia. Logo K3, K9 e os dois rearm ficam como estão até Q4. Nenhum `endDragTarget()` foi introduzido (`hostDrag.hpp` não chama, a sonda B prova que não existe `KwDrag::end`).

**Dependência de Q4 identificada:** posse do drag por sessão (adquirida quando `begin` devolve `BEGIN_STARTED` e `target()` não é nulo; invalidada por `ended` com contador de geração), necessária para K3 (6 pontos), K9, os 2 rearm e para o passo 2 do unload. ## 5. Q4 — restauração de estado no descarregamento (proposta revisada, não implementada)

Hoje `PLUGIN_EXIT` (`main.cpp:526–542`) **não** encerra drag/grab iniciado pelo plugin (L17, `LEDGER.md:45`; `QUIESCENCE.md:30`). A regra do protocolo: o passo 2 só encerra o que é do plugin; "um arrastar iniciado por atalho do usuário (bind do host) não é nosso".

**Por que identidade do alvo não basta (revisão 1):** o host encerra drags sozinho a cada tecla/botão (§2), e as flags do plugin ficam velhas (ex.: hoje `grabActive` só é limpo por Escape, `main.cpp:457–459`, mas qualquer tecla encerra o drag no host). Contraexemplo: drag do plugin na janela T encerrado pelo host; o usuário inicia por bind um drag na **mesma** T; `WP<ITarget>` ainda casa com `target()` → o unload encerraria o drag do usuário. Não depende de reuso de ponteiro.

**Proposta: posse por sessão, invalidada pelo sinal do host.**
1. Estado do plugin: `bool ownsDrag` + `WP<Layout::ITarget> ownedTarget`, e um `CHyprSignalListener` em `g_layoutManager->dragController()->m_events.ended` (0.57; tipo provado na sonda K) que faz `ownsDrag = false; ownedTarget.reset()`. Como todo fim de sessão com alvo passa por `dragEnd` e emite `ended` (scope guard), qualquer fim — tecla, botão, Escape, recusa — invalida a posse.
2. Adquirir posse **só** quando o helper K1/K2 realmente chamou `beginDragTarget` (não nos retornos antecipados "já há alvo", "sem janela" e "recusado pela decoração", para não adotar o drag de outro) **e** `target()` não é nulo depois da chamada (`dragBegin` pode recusar e já emitir `ended` dentro dela). Vale para toda partida: `handleMovement`, `rearmDrag`, fim do unsnap, `luaGrab`.
3. Passo 2 do unload: marcar `unloading = true`; `if (ownsDrag && ownedTarget.lock() == target()) endDragTarget();` (o `ended` limpa a posse); depois zerar as flags de interação (`m_bDraggingThis`, `m_bDragPending`, `grabActive`, `grabSwallowPress`, `m_unsnapAnim`, `m_rearmPending`, …).
4. **Reentrada síncrona é possível e precisa ser tratada (correção da revisão 1):** `endDragTarget()` chama `checkInputOnDecorations(DRAG_END)` → `onInputOnDeco` pela vtable do `CHyprBar` (corpo padrão do host, vtable no módulo), `fullWindowFocus` → listener `window.active` do plugin (`main.cpp:490`, `onFocusChanged` nas barras), `setTargetGeom`/damage → métodos virtuais das decorações; e o listener de `ended` do item 1. Tudo isso roda **com o módulo mapeado**, durante o passo 2. Requisitos: esses callbacks não podem agendar trabalho diferido (timer do tooltip, rearm, preview) quando `unloading`; o passo 2 deve vir **antes** da remoção de listeners/decorações/timers (passos posteriores) e o listener de `ended` deve ser removido junto dos demais. A prova de que **nenhum** callback roda **depois** do unmap é do protocolo de lifecycle (Q3), não desta análise.
5. **Sessão substituída sem `ended`:** verificado que não ocorre pelos chamadores do host — todos os `beginDragTarget` do host exigem ausência de alvo antes: `Actions::mouse` (`U:ConfigActions.cpp:1703`), pedidos do cliente `onMoveRequest`/`onResizeRequest` (`U:Window.cpp:1861,1871`, que usam `exclusiveDeviceGrab=true`) e redimensionar pela borda (`U:InputManager.cpp:876`). Logo, uma nova sessão só começa depois de um `ended`, que invalida a posse. Os helpers do plugin (K1/K2) mantêm a mesma guarda. A comparação `ownedTarget.lock() == target()` fica como defesa adicional, não como mecanismo principal.
6. **Invariante de ordem (revisão 2):** a guarda de alvo não prova sozinha que o `ended` antigo chega antes de uma sessão nova, porque `ended` é emitido na **saída** de `dragEnd` e callbacks reentrantes rodam antes disso. Exigir: (i) nenhum callback do plugin alcançável durante `dragEnd` (§5 item 4) pode iniciar drag de forma síncrona (os helpers K1/K2 recusam se `unloading` ou se chamados enquanto um `dragEnd` está em curso); (ii) posse por **geração**: o listener de `ended` incrementa um contador; a posse guarda o valor do contador no momento da aquisição e só vale se ele não mudou. Um `ended` tardio de sessão antiga invalida a posse nova — falha **conservadora** (o unload deixa de encerrar um drag do plugin, que o host encerra no próximo botão/tecla), nunca encerra drag do usuário. Nenhum caminho de início reentrante foi demonstrado no código atual; é condição para a implementação de Q4.

Testes Q4 (B1-D3 aninhado): unload com (a) drag pela barra ativo; (b) grab do menu ativo; (c) unsnap em animação; (d) drag por bind do usuário ativo, com e sem drag anterior do plugin na mesma janela já encerrado por tecla; (e) flag velha (`grabActive` após tecla não-Escape); (f) pedido de move do cliente durante drag do plugin (deve ser recusado pelo host). Critério: alvo vazio em (a)–(c); intacto em (d)–(e); em (f) o drag do plugin continua e o pedido é ignorado; nenhum timer/callback agendado pelo passo 2; nenhuma chamada ao módulo após o passo 8.

// Starting a pointer drag (move/resize) on Hyprland 0.57, where CKeybindManager::changeMouseBindMode is gone. This is
// the START half of the 0.56.2 body (O:managers/KeybindManager.cpp:949-968) on the 0.57 primitives, nothing more:
//   - a drag already in progress (anyone's) is left alone: nothing is ended, nothing is started;
//   - the window is the one under the pointer (as before; for the menu's resize that is the 0.56.2 behaviour too);
//   - a non-fullscreen MOVE asks the window's decorations first (INPUT_TYPE_DRAG_START), as before;
//   - beginDragTarget keeps its defaults (no forced edge, exclusiveDeviceGrab = false), as before.
// Ending a drag is NOT here: without knowing whose drag is active (session ownership, Q4), ending would also end drags
// started by other components. See docs/port-0-57/P8-DRAG.md.

namespace KwDrag {
    enum eBeginResult : uint8_t {
        BEGIN_STARTED = 0,      // beginDragTarget was called (the host may still refuse inside it)
        BEGIN_ALREADY_DRAGGING, // a drag was in progress: left untouched
        BEGIN_NO_WINDOW,        // nothing under the pointer (0.56.2: passEvent)
        BEGIN_REFUSED_BY_DECO,  // a decoration took the drag start (0.56.2: passEvent = false)
        BEGIN_BAD_MODE,         // not MBIND_MOVE / MBIND_RESIZE: nothing done
    };

    // MODE must be MBIND_MOVE or MBIND_RESIZE; anything else does nothing (0.56.2 ended the drag for MBIND_INVALID,
    // which this helper deliberately does not do).
    inline eBeginResult begin(eMouseBindMode MODE) {
        if (MODE != MBIND_MOVE && MODE != MBIND_RESIZE)
            return BEGIN_BAD_MODE;
        if (g_layoutManager->dragController()->target())
            return BEGIN_ALREADY_DRAGGING;

        const auto      MOUSECOORDS = g_pInputManager->getMouseCoordsInternal();
        const PHLWINDOW PWINDOW =
            Desktop::viewState()->hitTest().windowAt(MOUSECOORDS, Desktop::View::RESERVED_EXTENTS | Desktop::View::INPUT_EXTENTS | Desktop::View::ALLOW_FLOATING);

        if (!PWINDOW)
            return BEGIN_NO_WINDOW;

        if (!Fullscreen::controller()->isFullscreen(PWINDOW) && MODE == MBIND_MOVE) {
            if (PWINDOW->presentation().checkInputOnDecorations(INPUT_TYPE_DRAG_START, MOUSECOORDS))
                return BEGIN_REFUSED_BY_DECO;
        }

        g_layoutManager->beginDragTarget(PWINDOW->layoutTarget(), MODE);
        return BEGIN_STARTED;
    }
}

#!/usr/bin/env python3
"""P8-B extraction.
  calls SRC_BARDECO SRC_MAIN OUT old|new
     old: the drag-START lines replaced in P8-B: `changeMouseBindMode(MBIND_MOVE)` not directly after a
          `changeMouseBindMode(MBIND_INVALID)` line (i.e. not a rearm), and the main.cpp `mode == "move" ? ...` grab;
     new: lines with `KwDrag::begin(`. Expect 2 (K1 handleMovement, K2 luaGrab).
  oldbody OSRC OUT   the verbatim 0.56.2 CKeybindManager::changeMouseBindMode body.
Also writes OUT.guards: the chain of enclosing control lines of each statement."""
import re, sys

ORDER = ["K1-handleMovement", "K2-luaGrab"]


def find(lines, pred):
    out = []
    for i, l in enumerate(lines):
        s = l.strip()
        if s.startswith("//") or not pred(i, l):
            continue
        out.append((i + 1, [l]))
    return out


def chain(lines, ln):
    res, ind = [], len(lines[ln - 1]) - len(lines[ln - 1].lstrip())
    for n in range(ln - 2, -1, -1):
        s = lines[n].strip()
        if s and not s.startswith("//") and len(lines[n]) - len(lines[n].lstrip()) < ind:
            res.append(s)
            ind = len(lines[n]) - len(lines[n].lstrip())
            if ind == 0:
                break
    return " <- ".join(res)


mode = sys.argv[1]
if mode == "calls":
    bar, main, out, kind = sys.argv[2:6]
    got = []
    for src in (bar, main):
        L = open(src, encoding="utf-8").read().split("\n")
        if kind == "old":
            pred = lambda i, l: ("changeMouseBindMode(MBIND_MOVE)" in l and "MBIND_INVALID" not in L[i - 1]) or 'changeMouseBindMode(mode == "move"' in l
        else:
            pred = lambda i, l: "KwDrag::begin(" in l
        got += [(src, ln, body, chain(L, ln)) for ln, body in find(L, pred)]
    assert len(got) == 2, f"{kind}: expected 2 statements, found {[(g[0].split('/')[-1], g[1]) for g in got]}"
    with open(out, "w") as f, open(out + ".guards", "w") as g:
        for k, (src, ln, body, ch) in enumerate(got):
            f.write(f"    case {k}: {{ // {ORDER[k]}\n#line {ln} \"{src}\"\n" + "\n".join(body) + "\n    } break;\n")
            g.write(f"{ORDER[k]}: {ch}\n")
    print(" ".join(f"{ORDER[k]}:{g[0].split('/')[-1]}:{g[1]}" for k, g in enumerate(got)))
elif mode == "oldbody":
    src, out = sys.argv[2:4]
    t = open(src, encoding="utf-8").read().split("\n")
    i = next(n for n, l in enumerate(t) if l.startswith("SDispatchResult CKeybindManager::changeMouseBindMode("))
    j = next(n for n in range(i, len(t)) if t[n].startswith("}"))
    open(out, "w").write(f'#line {i+1} "{src}"\n' + "\n".join(t[i : j + 1]) + "\n")
    print(f"changeMouseBindMode {i+1}-{j+1}")

#!/usr/bin/env python3
"""P8-B diff audit: every changed line (BASE -> CAND) must be a removed old extracted statement, an added new extracted
statement (one statement per line: one ';' outside literals/comments, no return/goto/break/continue/throw), the
`#include "hostDrag.hpp"` line, or a comment; identical lines re-aligned inside one hunk cancel.
usage: diff_audit.py BASE CAND OLD_CALLS NEW_CALLS   (exit 1 on any unexplained line or unequal statement counts)"""
import collections, difflib, re, sys

base, cand, oldc, newc = sys.argv[1:5]
b = open(base, encoding="utf-8").read().split("\n")
c = open(cand, encoding="utf-8").read().split("\n")


def stmt_lines(inc):
    return {l.rstrip("\n").strip() for l in open(inc, encoding="utf-8") if not l.startswith(("    case ", "#line", "    } break;"))}


def single_statement(s):
    code = re.sub(r'"(?:[^"\\]|\\.)*"' + r"|'(?:[^'\\]|\\.)*'", '""', s).split("//")[0]
    return code.count(";") == 1 and code.rstrip().endswith(";") and not re.search(r"\b(return|goto|break|continue|throw)\b", code)


old_ok, new_ok = stmt_lines(oldc), stmt_lines(newc)
bad, counts = 0, collections.Counter()
for tag, i1, i2, j1, j2 in difflib.SequenceMatcher(None, b, c, autojunk=False).get_opcodes():
    if tag == "equal":
        continue
    gr, ga = collections.Counter(), collections.Counter()
    for s in (x.strip() for x in b[i1:i2]):
        if s in old_ok: counts["-stmt"] += 1
        elif s.startswith("//"): counts["-comment"] += 1
        else: gr[s] += 1
    for s in (x.strip() for x in c[j1:j2]):
        if s in new_ok and single_statement(s): counts["+stmt"] += 1
        elif s == '#include "hostDrag.hpp"': counts["+include"] += 1
        elif s.startswith("//"): counts["+comment"] += 1
        else: ga[s] += 1
    moved = gr & ga
    counts["realigned"] += sum(moved.values())
    for s, k in list((gr - moved).items()) + list((ga - moved).items()):
        bad += k
        print(f"UNEXPLAINED change in hunk base {i1+1}-{i2} / cand {j1+1}-{j2}: '{s[:120]}'")
print("diff audit:", dict(counts), "unexplained:", bad)
sys.exit(1 if bad or counts["-stmt"] != counts["+stmt"] else 0)
