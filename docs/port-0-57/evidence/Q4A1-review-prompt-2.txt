## 7. Limitações remanescentes

- **Captura de entrada (C1/C2):** sem prova de posse, o plugin não pode encerrar o próprio drag quando o host ignora a soltura. `PROTO::inputCapture->isCaptured()` é visível nos headers instalados, mas só diria que o host **não** encerrará. Liveness sob captura fica pendente de decisão.
- **Núcleo Lua:** `floatWindow` via `hl.dsp.window.float` encerra qualquer drag ativo e não há `target()` no Lua. Fora do modelo.
- **Ordem:** `snapOnRelease` passa a rodar antes do fim pelo host. O efeito real de `Actions::move` sobre alvo arrastado (DefaultFloatingAlgorithm.cpp:147–149, 235–244; `setTargetGeom` no `dragEnd`) não é decidível host-free.
- **Grab** termina na soltura do clique, não no press. Clique depois de o host já ter encerrado o grab passa ao aplicativo (antes era engolido).
- **Hit-test:** rearm e unsnap redesenhado chamam o helper, que escolhe a janela sob o ponteiro. Depois que o host para o move (Shift), o ponteiro pode estar sobre outra janela. Preexistente; exige conferir a janela antes do início. Não modelado.
- **Peculiaridades nativas:** press engolido com drag ativo e soltura repassada (B5, M3); com captura, o cliente fica com o press (C1/C2 em `absent`).
- **Defeito atual achado:** com dois ponteiros, `cur`/`veto-rc`/`naive5` cancelam a soltura do segundo por causa de `m_bCancelledDown` do primeiro, deixando botão preso (B5).
- **Fidelidade do modelo:** réplica manual. Não modela hotkeys, binds reais além de um bind de group bar, toque com controlador, `updateDragWindow` completo, hit-test, nem as ações não auditadas. R4 sobre fim do Kwinish não se aplica à alternativa 5 (não há entradas de fim). Drags de terceiro reiniciados dentro do fim do host continuam sendo comportamento do host (R4i, `h`).

## 8. Veredito e recomendação

A alternativa 5 resolve, **no modelo e para o plugin C++**, a segurança (O1) e o bloqueio de entrada (O3), sem lifecycle novo. **Não** satisfaz liveness em todos os casos: sob captura de entrada o drag do próprio Kwinish sobrevive à soltura (regressão). O núcleo Lua ainda pede fins indiretos. Pela regra do dono, **Q4-A continua BLOQUEADA**.

Recomendação: **redesenho delimitado antes de qualquer implementação**. Decisões necessárias:
1. política sob captura: aceitar o atraso até a próxima tecla/clique não capturado, ou outra solução sem fim não comprovado;
2. guarda/decisão para os `floatWindow` do Lua;
3. aceitar as diferenças do §7 (grab na soltura, ordem do snap, clique pós-grab);
4. conferência de janela no rearm.

Com isso decidido, a próxima etapa seria uma **implementação limitada** autorizada à parte, com testes do repositório vermelho-primeiro e roteiro ao vivo do dono.

// keybind manager ending any drag on every non-captured button/key event, and forwarding to the client.
// Plugin side replicates the CURRENT event routes of plugin/barDeco.cpp and plugin/main.cpp (listed per site below).

#include <map>

enum eWhere { AT_BAR, AT_BODY, AT_ELSEWHERE };

    bool cancelled = false;

struct World;
// ---------------------------------------------------------------------------------------------------------------------
// One Kwinish title bar (CHyprBar) on one window.
struct Bar {
    SPT  win;
    bool dragging = false, cancelledDown = false, pending = false, rearmPending = false;
    bool snapped = false, unsnapChecked = false, unsnapAnim = false, deferredUnsnap = false;

struct World {
    CHost                      h;
    eVariant                   v;
    std::unique_ptr<PolVeto>   veto; // V_VETO only (recheck variant)
    std::vector<Bar>           bars;

    bool                       focusMoved = false;        // focus left the bar's window between press and release

        t->name = n;

        return t;

        bars.push_back({});
        bars.back().win = w;
        return bars.back();

        switch (v) {
            case V_VETO: return veto->begin(t, m);
            case V_ALT5RC: return kwDragBeginRechecked(h, t, m);

struct SScenario {
    const char*                name;
    const char*                what;
    std::function<void(World&)> body;
};
struct SResult {
    std::vector<std::string> o1, o2, o3, o4, spec, info, host;
    bool                     hasDrag = false;
    std::string              fin;
};

static SResult run(eVariant v, const SScenario& sc) {
    World w(v);
    sc.body(w);
    w.h.runIdle();
    SResult r;
    r.o1 = Truth::violations(w.h);
    r.o2 = w.o2;
    // O2: every Kwinish-started session is finished by the end of the scenario (all buttons released)
    if (auto s = Truth::current(w.h); s && s->who == W_KWINISH) r.o2.push_back("Kwinish drag on " + s->target + " still active after the interaction");
    // O3: input not blocked: no stale held button, client pairing (collected), and the plugin did not keep alive a
    // drag that the native host (no plugin) would have ended
    r.o3 = w.o3;
    if (!w.held.empty()) r.o3.push_back("host keeps a released button as held");
    for (const auto& id : w.clientPressed) {
        if (w.hostSwallowedRelease.contains(id)) w.notes.push_back("host quirk: release swallowed because a drag was active (client keeps the press)");
        else r.o3.push_back("client still thinks a button is pressed");
    }
    if (auto s = Truth::current(w.h); s && w.blocked.contains(s->id))
        r.o3.push_back(std::string("release/click cancelled by Kwinish while this drag was active; still active: ") + whoName(s->who) + ":" + s->target);
    // O4: final consistency between host and plugin state
    const auto cur = Truth::current(w.h);
    r.hasDrag      = cur.has_value();
    r.fin          = cur ? std::string(whoName(cur->who)) + ":" + cur->target + " mode=" + std::to_string(w.h.mode()) : "no drag";
    if (w.h.wasDraggingWindow()) r.o4.push_back("wasDraggingWindow left set");
    if (!cur && w.h.mode() != M_INVALID) r.o4.push_back("mode set without a drag");
    for (auto& b : w.bars)
        if (b.dragging || b.pending || b.cancelledDown || b.unsnapAnim || b.deferredUnsnap) r.o4.push_back("bar flags left set after the interaction");
    if (w.grabActive || w.grabSwallowPress) r.o4.push_back("grab flags left set");
    for (auto& b : w.bars)
        if (b.unsnapSteps) r.o4.push_back("unsnap step counter left set");
    if (cur && w.h.mode() == M_INVALID) r.host.push_back(std::string("host-caused: live ") + whoName(cur->who) + " drag with mode INVALID (enclosing dragEnd, R3)");
    r.spec = w.spec;
    r.info = w.notes;
    return r;
}

}

    using IPolicy::IPolicy;
    uint64_t                generation = 0, acquisition = 0;
    std::optional<uint64_t> ownedAt;
    WPT                     ownedTarget;
    CHyprSignalListener     listener;
    bool                    inBegin = false, inEnd = false, unloading = false;
    bool                    recheck = false; // helper variant (see kwDragBeginRechecked)
    int                     vetoes = 0;
    const char*             name() const override { return "veto"; }
    void                    disarm() { ++acquisition; ownedAt.reset(); ownedTarget.reset(); listener.reset(); } // veto: token + listener
    bool                    ambiguous() const { return h.wasDraggingWindow(); }
    bool                    owns() const override {
        if (!listener || !ownedAt || *ownedAt != generation) return false;     // (b)
        if (ownedTarget.expired() || h.target() != ownedTarget.lock()) return false; // (c)
        return true;
    }
    eBeginResult begin(SPT t, eMode m) override {
        if (unloading || inBegin || inEnd) return REFUSED;                 // (e)
        if (ambiguous()) { ++vetoes; return REFUSED; }                     // (d) do not start inside a host end
        if (h.target()) return ALREADY;
        inBegin = true;
        Hyprutils::Utils::CScopeGuard g([this] { inBegin = false; });
        const uint64_t tok = ++acquisition;
        listener           = h.m_events.ended.listen([this, tok] {
            if (tok != acquisition) return;                                // (b) stale snapshot callback
            ++generation;
            disarm();
        });
        const uint64_t G0 = generation;
        const auto     r  = recheck ? kwDragBeginRechecked(h, t, m) : kwDragBegin(h, t, m);
        if (r != STARTED) { disarm(); return r; }                          // (a) e.g. the group bar took the drag
        if (generation != G0 || h.target() != t) { disarm(); return REFUSED; } // (a)
        ownedAt     = G0;
        ownedTarget = t;
        return STARTED;
    }
    bool endOwned() {
        if (inEnd || inBegin) return false;                                // (e)
        if (ambiguous()) { ++vetoes; return false; }                       // (d)
        if (!owns()) return false;
        disarm();                                                          // (e) consume before the call
        inEnd = true;
        Hyprutils::Utils::CScopeGuard g([this] { inEnd = false; });
        return h.endDragTarget();
    }
    void requestEnd() override { (void)endOwned(); }
    void requestRearm(SPT t, eMode m) override {
        if (endOwned()) (void)begin(t, m);
    }
    void unload() override { unloading = true; (void)endOwned(); disarm(); }
};

// Candidate + helper that re-checks target() after the DRAG_START dispatch (review 1 major).
struct PolVetoRecheck : PolVeto {
    explicit PolVetoRecheck(CHost& h_) : PolVeto(h_) { recheck = true; }
    const char* name() const override { return "veto-rc"; }
};

// ===== ALTERNATIVE (needs deferred work = lifecycle authorization): same proof, end executed at idle ================
// End entries only RECORD the request with the current acquisition token; an idle callback (doLater) re-checks
// ownership when no dragEnd frame and no `ended` emission is on the stack, so every `ended` of a finished end has been
// delivered. Must be cancelled in PLUGIN_EXIT (removeDoLater/doLaterLock) - not authorized in this step.
struct PolDefer : PolVeto {
    using PolVeto::PolVeto;
    std::optional<uint64_t> pendingFor;
    std::optional<eMode>    pendingRearm;
    SPT                     rearmTarget;
    bool                    scheduled = false;
    const char*             name() const override { return "defer"; }
    void                    schedule() {
        if (scheduled) return;
        scheduled = true;
        h.idleQueue.push_back([this] {
            CHost::CallerScope s(h, W_KWINISH);
            scheduled      = false;
            const auto tok = pendingFor;
            const auto rm  = pendingRearm;
            auto       rt  = rearmTarget;
            pendingFor.reset(); pendingRearm.reset(); rearmTarget = nullptr;
            if (!tok || *tok != acquisition) return; // ownership changed since the request
            if (endOwned() && rm) (void)begin(rt, *rm);
        });
    }
    void requestEnd() override {
        if (unloading || !owns()) return;
        pendingFor = acquisition;
        schedule();
    }
    void requestRearm(SPT t, eMode m) override {
        if (unloading || !owns()) return;
        pendingFor = acquisition; pendingRearm = m; rearmTarget = t;
        schedule();
    }
    void unload() override { pendingFor.reset(); pendingRearm.reset(); rearmTarget = nullptr; PolVeto::unload(); }
};

// ===== ALTERNATIVE (needs function hooks on dragBegin/dragEnd = hook + lifecycle authorization) =====================
// A hook gives a real session identity: any begin or end after the acquisition changes the sequence.
struct PolHook : IPolicy {
    using IPolicy::IPolicy;
    std::optional<uint64_t> ownedSeq;
    WPT                     ownedTarget;
    bool                    inBegin = false, inEnd = false, unloading = false;
    const char*             name() const override { return "hook"; }
    bool owns() const override { return ownedSeq && *ownedSeq == h.hookSeq() && !ownedTarget.expired() && h.target() == ownedTarget.lock(); }
    eBeginResult begin(SPT t, eMode m) override {
        if (unloading || inBegin || inEnd) return REFUSED;
        if (h.target()) return ALREADY;
        inBegin = true;
        Hyprutils::Utils::CScopeGuard g([this] { inBegin = false; });
        const uint64_t S0 = h.hookSeq();
        const auto     r  = kwDragBegin(h, t, m);
        if (r != STARTED) return r;
        if (h.hookSeq() != S0 + 1 || h.target() != t) return REFUSED; // anything else began/ended meanwhile
        ownedSeq    = h.hookSeq();
        ownedTarget = t;
        return STARTED;
    }
    bool endOwned() {
        if (inEnd || inBegin || !owns()) return false;
        ownedSeq.reset();
        inEnd = true;
        Hyprutils::Utils::CScopeGuard g([this] { inEnd = false; });
        return h.endDragTarget();
    }
    void requestEnd() override { (void)endOwned(); }
    void requestRearm(SPT t, eMode m) override { if (endOwned()) (void)begin(t, m); }
    void unload() override { unloading = true; (void)endOwned(); ownedSeq.reset(); }
};
