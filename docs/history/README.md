## Validade e referências históricas

Os originais podem conter instruções antigas, prompts, caminhos privados, versões ausentes e links que só faziam sentido no diretório original. Eles são evidência, não comandos atuais. A validação informa essas limitações separadamente dos links da documentação vigente; mover um original não autoriza modificar seu texto.

`repository-originals.zip` permite recuperar exatamente os 28 documentos do baseline, inclusive os atualizados nos caminhos atuais. Os históricos movidos também conservam seus bytes originais. O pacote externo permanece na raiz e tem cópia idêntica no acervo. `SOURCES.json` e `SHA256SUMS` permitem verificar a preservação; `MANIFEST.json` registra a consolidação.

O OpenSpec vigente, mudanças ativas, arquivos arquivados e worktrees existentes não fazem parte desta reorganização. Seus estados são conferidos contra o inventário inicial.
